# street-01 制作说明

> 本文记录从参考图到可交付资产的全部技术决策，便于后续整城扩展时复用与校准。

## 1. 目标与边界

- 只做**一条街**，但按「可扩成整城」的模块化标准来做：构件可复用、材质可平铺、语义可检索。
- 全部为新增文件；历史建模版本未被读取、修改或覆盖。
- 项目规范见 `docs/01-overview.md`：风格定位、坐标、目录、PBR 通道、验收标准均为硬约束。

## 3. 调色板提取

- 材质研究板实际为 **3 列 × 4 行**（按实际生图结果校正），逐格取中心 62% 区域、
  剔除极值后取 RGB 中位数，得到 12 种基色：青石板 `#5C5F58`、青砖 `#69645A`、
  夯土 `#66422E`、白灰 `#ADA799`、朱漆 `#451714`、老木 `#67553F`、青瓦 `#494843`、
  彩画 `#303731`、铜绿 `#3C3B2D`、灯笼纱 `#91918B`、靛蓝 `#161D36`、树皮 `#574B3D`。
- 街道全景图做 LAB 空间 K-Means（k=12）得到环境色，用于光照与雾预设。
- **去光照补偿**：参考照片自带照明与阴影，不能直接当 albedo。生成器按材质施加
  `gain`（1.0–1.78）提亮并轻微增饱和，保持色相，使 albedo 不含烘焙光照。
- 其余 17 种材质（路缘石、积水、格扇纸、匾额、鎏金铜、竹编、陶器、麻袋、叶片、
  苔藓、污渍等）从上述基色衍生，均标注来源。

## 4. PBR 贴图生成

### 4.1 噪声体系

`src/pbr/texcore.py` 实现四类**严格周期**噪声（四边无缝）：

- `grid_noise`：周期双线性 value noise（smoothstep 插值，坐标取模）
- `fbm` / `ridged`：分形叠加，用于风化、裂纹、木纹、石纹
- `voronoi`：带周期边界的 Voronoi（3×3 邻域搜索），返回最近/次近距离与 cell id，
  用于石板分块、漆面龟裂、夯土颗粒
- `stripes` / 编织 / 极坐标函数：用于瓦垄、织物、瓦当、轮制陶纹

### 4.2 通道与无缝

每个材质输出 `albedo / normal / roughness / metallic / ao / height / orm`：

- `normal` 由 height 求梯度得到（OpenGL +Y）
- `ao` 由 height 与高斯模糊的空腔差导出，**不写入 albedo**
- `orm` 打包 R=AO、G=Roughness、B=Metallic，glTF 的 `metallicRoughnessTexture`
  与 `occlusionTexture` 共用同一张图
- `wrap_fix`：在 8 像素边缘带做交叉淡化，把左右/上下边界统一到平均值。
  实测 29 种材质接缝误差全部为 **0.00**
- 尺寸：主材质 2048²（青石板、青砖、夯土、抹面、朱漆、木枋、青瓦、彩画等 12 种），
  其余 1024²

透明材质（叶片图集、污渍贴花）额外输出 `opacity`，并在 glTF 阶段合成为 RGBA
basecolor，分别使用 `MASK`（叶片）与 `BLEND`（污渍）。自发光材质（灯笼纱、格扇纸）
额外输出 `emissive`。

### 4.3 材质覆盖

六大类 29 种：路面 6、建筑 12、装饰 5、道具 2、自然 3、细节 1。
每种附 `material.json`（基色、通道、尺寸、平铺尺度、粗糙度区间、金属度、
法线强度、seed、接缝误差、参考依据）。

### 4.4 店招

14 家店名用本地 Noto Serif CJK 字体烘焙成黑漆金字横匾与竖幌，加噪点、划痕、
褪色做旧；再拼成两张图集（匾额 2048×512、布幡 512×2048），用 UV 子区域选择，
把 28 张店招压成 2 个材质，减少纹理切换。

## 5. 几何与 glTF

### 5.1 自研 glTF 2.0 写出器

`src/geometry/gltf_writer.py` 不依赖任何建模软件，直接写标准 glTF：

- 顶点 `POSITION / NORMAL / TEXCOORD_0`，uint32 索引，accessor 带 min/max
- 按 **`语义路径 + 材质`** 合并几何（如 `North/Buildings/wineshop_00`），
  既保留可读节点树又控制 draw call
- UV 按**物理尺度**平铺：每个面用真实尺寸除以材质 `tile_meters`，
  因此 120 m 街面与 0.2 m 瓦当的纹理密度一致
- 同时输出外置纹理 `.gltf` 与纹理内嵌 `.glb`（GLB 中 image 由 `uri` 改为 `bufferView`）
- `_prune_unused`：裁掉未被引用的材质/纹理/图片，使模块 GLB 只内嵌自身需要的贴图
- `KHR_lights_punctual`：平行光 + 12 盏灯笼点光 + 1 盏香炉点光

### 5.2 建筑构成

每栋 14.4 m 面阔 / 7.4 m 进深，四开间五柱：

- 台基、三级踏步、柱础、朱漆檐柱（前后各 5 根）
- 三种墙体材质轮换、槛墙、格扇糊纸窗（横棂 + 竖棂）、板门与鎏金门环
- 额枋、**柱头与补间斗拱**（栌斗 / 两层华拱 / 横拱 / 散斗 / 令拱，每攒 12+ 构件）
- 椽子、檐板、**举折双坡屋顶**：每坡 4 段凹曲面（`y = eave + (ridge-eave)·(1-t)^1.5`，
  脊陡檐缓），瓦垄立体脊线、檐口圆瓦当、垂脊、正脊与鸱吻
- 匾额、竖幌、4 盏灯笼（红绸 3 / 纸灯 1，含挂绳、铜盖、流苏）
- 3 栋为二层重檐楼阁，二层柱网缩进 0.9 m、屋顶出挑收至 0.62 m

### 5.3 街面与道具

青石板车行道、青砖人行道、路缘石分块、两侧排水沟与沟盖、车辙泥、
修补砖块、积水、污渍贴花、沟边苔藓、城外夯土地基（保证任意机位不露空）。
市井道具：12 个摊位、8 棵槐树（主干 / 分枝 / 叶片 billboard）、10 根拴马桩、
6 座石灯、2 根旗杆、货箱组、水井与辘轳、香炉。远景城门楼含三门洞城台、
城楼柱网、双坡屋面、阙楼与坊墙。

### 5.4 模块库

7 件独立 GLB：灯笼、摊位、水井、槐树、拴马桩、石灯、三开间店铺。
可在 DCC / 引擎里直接实例化扩展成整城。

## 8. 技术取舍与已知边界

- **程序化而非照片扫描**：全部贴图由噪声生成，优势是无缝、可平铺、可复现、
  参数可调；代价是不等同真实扫描材质。生图参考用于配色与纹样校准。
- **石板形状**：采用 Voronoi 分块，呈现老城弹石路质感；若需更规整的矩形石板，
  调整 `materials.masonry` 的分块方式即可，无需改动几何。
- **灯笼红色**：复用灯笼纱全部通道，仅用 glTF `baseColorFactor` 染朱红，
  避免为单一颜色新增一整套贴图。
- **远景城楼**：为剪影级精度（配合雾），不作为近景资产。
- **预览与生产资产分离**：预览是 512px 贴图；生产用 `assets/textures/` 的 2K 原图与
  `assets/models/` 的 GLB。
- **灯光**：glTF 内带 KHR_lights_punctual，预览页另行控制光照以获得时段切换能力
  （加载时把 glTF 灯光设为不可见）。
- 天空、雾、水波、树叶风动等环境效果在预览层实现，未烘焙进模型。
