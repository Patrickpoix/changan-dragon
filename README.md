# 《龙游长安》

**唐长安开放世界3D页游** · 国风漫剧/电影画风质感

---

## 项目简介

以盛唐长安城为背景的开放世界3D探索页游，基于Three.js r160构建，呈现国风电影级视觉质感。

---

## 核心特色

### 🏯 完整长安城
- **108坊**：程序化生成的唐代坊市格局
- **核心地标**：大明宫、太极宫、兴庆宫、曲江池、大雁塔、小雁塔、青龙寺、西明寺、朱雀大街、东西市、明德门
- **完整水系**：曲江池、龙池、护城河（含游船、石桥）
- **城墙系统**：完整城墙+四角角楼+城门

### 🎨 国风电影质感
- **ACES电影级色调映射**
- **黄金时刻暖金色光影**
- **国风薄雾效果**
- **共享PBR材质系统**

### 🎮 开放世界探索
- **步行/骑行/飞行** 三种移动模式
- **诗笺收集系统**
- **昼夜循环系统**
- **动态NPC城市生活**
- **五声音阶环境音景**
- **天气系统**

---

## 技术栈

- **引擎**：Three.js r160 正式版
- **渲染**：WebGL2 + ACES色调映射 + SAO环境光遮蔽 + Bloom辉光 + FXAA抗锯齿
- **材质**：共享PBR材质库 + 卡通渲染着色
- **优化**：建筑批处理 + 实例化 + 空间分区 + LOD
- **存档**：localStorage
