# 《龙游长安》

**唐长安开放世界3D页游** · 国风漫剧/电影画风质感

---

## 项目简介

以盛唐长安城为背景的开放世界3D探索页游，基于 Three.js r160 构建。历史复原与艺术幻想并行。**当前只开发长安城**（WORLD=±780/±660），完整长安扩展规划见 docs/WORLD_ARCHITECTURE.md。

---

## 核心特色

### 🏯 长安城
- **108坊**程序化生成，坊墙坊门齐备
- **核心地标**：大明宫、太极宫、兴庆宫、曲江池、大雁塔、小雁塔、青龙寺、西明寺、朱雀大街、东西市、明德门
- **城墙系统**：四面城墙+四角角楼+垛口+城门门楼
- **完整水系**：曲江池/龙池/太液池/护城河（水面Shader波纹高光昼夜联动）

### 🎨 电影质感
- ACES色调映射 + SAO环境光遮蔽 + Bloom辉光 + FXAA
- 共享PBR材质库，HDRI环境贴图（Poly Haven）
- 统一昼夜主循环（updateDayNight）

### 🎮 开放世界
- 步行/骑行/飞行三种移动模式
- 16枚诗笺收集（localStorage存档）
- 昼夜切换、天气系统、NPC城市生活、画舫
- 四种镜头模式 + 电影赏景运镜

## 技术架构

### 启动加载（boot.js v8）
- **关键路径**：25个小文件(~1MB)并行下载 → buildWorld() → 开始界面
- **后台延迟**：scene-materials.js(7MB PBR纹理) + runtime-models.js(9.58MB GLB模型)
- **开始界面预热**：requestIdleCallback预生成PMREM+后处理管线+材质编译
- **Service Worker**：静态资源缓存，重复访问秒开

### 增强模块（按Owner分类）

通过 `__enhance.register(owner, fn, priority)` 注册，GAME.ready后RAF分帧执行。

| Owner | 优先级 | 职责 |
|-------|--------|------|
| performance | 30 | 纹理各向异性 + 阴影±140m |
| weather | 35 | 晴/阴/雨 + 雨滴粒子 |
| landmarks | 40 | 东西市牌坊 + 塔前石碑 |
| vegetation | 50 | 花圃/竹林（种子随机可复现） |
| water | 60 | 护城河三面 + 木桥6座 + 岸石芦苇 |
| night-light | 70 | 灯笼 + 7组点光源昼夜联动 |
| outside | 80 | 城外驿站/水井/里程碑/树 |

### 素材共享策略
- 所有enhance模块使用共享UNIT_*几何体和MAT材质
- 不重复创建已有系统（水面/天空/树木/角楼/灯柱）
- GLB模型从runtime-models.js共享加载，不重复存储
