# 龙游长安 · 盛唐开放世界页游

步行、骑行或乘风飞行，漫游盛唐长安城。

## 特色

### 开放世界
- **108坊** 完整还原唐代长安棋盘格局
- **朱雀大街** 26米宽御道，贯穿南北
- **大明宫** 含元殿+麟德殿，宫阙巍峨
- **东西市** 繁华商业区，酒肆茶坊布庄粮行
- **曲江池** 诗意水景，荷花芦苇亭子小桥

### 视觉质感
- 国风漫剧/电影画风
- ACES电影级色调映射
- PBR真实材质（normal + roughness贴图）
- SAO屏幕环境光遮蔽
- Bloom辉光 + FXAA抗锯齿
- 暖金日光 + 青灰雾霭的国风配色

### 动态氛围
- 🌸 花瓣飘落（桃花/樱花）
- 🐦 飞鸟盘旋
- 🎵 五声音阶环境音景
- 🌤️ 晴/阴/雨天气系统
- 🏮 街道灯笼

### 探索玩法
- 🚶 步行 / 🚲 骑行 / ✈️ 飞行 三种移动模式
- 📍 16个景点（朱雀大街/大明宫/大雁塔/曲江池等）
- 📜 20首唐诗诗笺收集
- 🎬 16个电影级赏景镜头

## 技术栈

- **引擎**：Three.js r160
- **渲染**：WebGL2 + 后处理管线
- **批渲染**：InstancedMesh + 空间分区 + LOD
- **天空**：自定义Shader（云层+太阳+星星）
- **材质**：Canvas程序化纹理 + CC0 PBR贴图

## 运行

直接打开 `index.html` 即可（需要HTTP服务器）：

```bash
npx serve .
# 或
python -m http.server 8000
```
