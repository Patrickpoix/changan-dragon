# 龙游长安 · 盛唐开放世界页游

步行、骑行或乘风飞行，漫游盛唐长安城。

### 开放世界
- **108坊** 完整还原唐代长安棋盘格局

- **大明宫** 含元殿+麟德殿，宫阙巍峨

- Bloom辉光 + FXAA抗锯齿
- 暖金日光 + 青灰雾霭的国风配色

### 动态氛围
- 🌸 花瓣飘落（桃花/樱花）

- 🎵 五声音阶环境音景（程序化合成）
- 🌤️ 晴/阴/雨天气系统
- 🏮 街道灯笼

### 探索玩法

## 核心建筑精修

### 主体建筑（121-133号模块）
- **朱雀大街**：中央御道石板 + 两侧排水沟 + 行道槐阵列
- **大明宫**：丹凤门重檐庑殿顶 + 朱红立柱阵列 + 殿前玉阶 + 斗拱层（坐斗/翘/昂）+ 彩绘斗拱
- **东西市**：店铺立面 + 朱红招牌（酒肆/茶坊/布庄/粮行）+ 带布篷摊位
- **曲江池**：湖岸石板步道 + 四角攒尖亭 + 荷花荷叶
- **城墙**：四面城墙 + 垛口 + 明德门城楼（重檐+门洞）+ 四角角楼
- **大雁塔**：七层楼阁式砖塔（逐层收分+出檐+金属塔刹）
- **小雁塔**：十五层密檐式砖塔（密集出檐+秀丽轮廓）
- **兴庆宫**：花萼相辉楼（重檐+立柱）+ 沉香亭（攒尖顶）+ 牡丹园 + 龙池
- **太极宫**：太极殿（重檐+11根立柱）+ 东西配殿 + 宫门

## 技术栈

- **引擎**：Three.js r160（正式版，669KB）
- **渲染**：WebGL2 + 后处理管线（ACES色调映射/SAO/Bloom/FXAA）
- **批渲染**：InstancedMesh + 空间分区 + LOD
- **天空**：自定义Shader（云层+太阳+星星）
- **材质**：Canvas程序化纹理
- **音频**：Web Audio API程序化合成

## 运行

直接打开 `index.html` 即可（需要HTTP服务器）：

```bash
npx serve .
# 或
python -m http.server 8000
```
