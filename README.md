# 《龙游长安》

**唐长安开放世界3D页游** · 国风漫剧/电影画风质感

---

## 项目简介

以盛唐长安城为背景的开放世界3D探索页游，基于Three.js r160构建，呈现国风电影级视觉质感。

---

## 核心特色

### 🏯 完整长安城
- **108坊**：程序化生成的唐代坊市格局
- **核心地标**：大明宫、太极宫、兴庆宫、曲江池、大雁塔、小雁塔、青龙寺、西明寺、朱雀大街、东西市、明德门
- **完整水系**：曲江池、龙池、护城河（含13艘游船、2座石桥、2座湖心亭）
- **城墙系统**：完整城墙+四角角楼（带中层结构）+城门

### 🎨 国风电影质感
- **ACES电影级色调映射**（曝光1.2）
- **黄金时刻暖金色光影**
- **国风暖灰薄雾效果**（60-650米雾距）
- **共享PBR材质系统**
- **暖橙色轮廓光**（增强立体感）
- **半球光暖调**（天空暖金/地面青绿）

### 🌳 丰富自然生态
- **行道树**：朱雀大街60棵行道树
- **宫殿园林**：大明宫35棵松树、太极宫25棵松树
- **曲江柳色**：曲江池25棵垂柳、龙池15棵垂柳
- **牡丹花海**：兴庆宫50株牡丹
- **荷塘月色**：曲江池40片荷叶+15朵荷花
- **岸畔芦苇**：曲江池40根、龙池25根
- **城外密林**：城外185棵树（东南/西南/东北/西北四片）

### 🏘️ 城外世界
- **护城河**：25米宽南护城河
- **村落聚落**：东南18间、西北12间农舍
- **驿站系统**：东南西北4座驿站（带围墙院子）
- **城外农田**：原系统70块城外农田

### 🏮 繁华唐夜
- **朱雀大街灯笼**：25组灯笼+点光源
- **宫殿灯火**：大明宫12组、太极宫10组暖金灯光

- **宫苑夜色**：兴庆宫、曲江池氛围灯光

### 🎮 开放世界探索

- **诗笺收集系统**

## 技术架构

### 引擎
- **Three.js r160 正式版**
- WebGL2 + ACES色调映射 + SAO环境光遮蔽 + Bloom辉光 + FXAA抗锯齿
- 共享PBR材质库 + 卡通渲染着色
- 建筑批处理 + 实例化 + 空间分区 + LOD

### 性能配置
- **桌面端**：DPR 2.0 + 阴影4096 + 各向异性16x
- **移动端**：DPR 1.5 + 阴影2048 + 各向异性16x

### 模块Owner划分（按系统分类）

| Owner模块 | 职责 | 规模 |
|-----------|------|------|
| `enhance/visual-grade.js` | 视觉调色/色调映射/雾效/光影/轮廓光 | ACES+国风暖灰雾+暖金光影 |
| `enhance/landmarks.js` | 地标精修/台阶/广场/角楼/牌坊 | 11地标4层台阶+3大广场+4角楼+2牌坊 |
| `enhance/vegetation.js` | 植被系统/树木/花卉/灌木 | 10种树配置+3种花卉+灌木 |
| `enhance/water.js` | 水景系统/游船/石桥/亭子/荷叶/芦苇 | 13船+2桥+2亭(带栏杆)+荷叶荷花芦苇 |
| `enhance/sky.js` | 天空系统/微调原Shader | 天顶+地平线+太阳色微调 |
| `enhance/outside.js` | 城外环境/护城河/村落/驿站/树林 | 4驿站+30农舍+185树+护城河 |
| `enhance/night-light.js` | 夜景灯光/灯笼/点光源 | 9组点光源+50灯笼+繁华唐夜 |
| `enhance/performance.js` | 性能优化/DPR/阴影/各向异性过滤 | 桌面4096阴影/移动2048+16x各向异性 |
