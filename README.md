# 《龙游长安》

**唐长安开放世界3D页游** · 国风漫剧/电影画风质感

---

## 项目简介

以盛唐长安城为背景的开放世界3D探索页游，基于 Three.js r160 构建。历史复原与艺术幻想并行：真实城墙、坊市、道路与宫殿地标依史料复原，同时加入国风漫剧式的奇观建筑与超现实场景。**当前只开发长安城**（约84平方公里历史尺度，游戏世界坐标 WORLD=±780/±660），不扩展其他城市。

## 技术架构

### 引擎
- **Three.js r160 正式版**（页游，上限高、易扩展）
- WebGL2 + ACES色调映射 + SAO环境光遮蔽 + Bloom辉光 + FXAA抗锯齿
- 共享PBR材质库 + Batch实例化（空间分区+LOD）
- 单一主循环（animate）：NPC/船只/自然/昼夜/诗笺/灯笼/水面/后处理统一驱动

### 增强模块（按Owner分类，统一生命周期调度器）

所有增强模块通过 `src/99-safe-init.js` 的 `window.__enhance.register(owner, fn, priority)` 注册，GAME.ready 后按优先级串行执行（间隔500ms），**取代旧式固定延迟setTimeout**。

| Owner | 优先级 | 职责 |
|-------|--------|------|
| visual-grade | 10 | 视觉自检（国风基调GRADE已整合进主循环，不重复设置） |
| sky | 20 | 天空自检（原系统天空Shader已完善） |
| performance | 30 | 纹理各向异性16x + 阴影范围±140m（保持近景精度） |
| landmarks | 40 | 东西市牌坊 + 大雁塔/小雁塔石碑（角楼/垛口/台阶原系统已有，不重复） |
| vegetation | 50 | 沉香亭花圃/大雁塔蓝花/太极宫菊花/曲江岸草/竹林（共享材质） |
| water | 60 | 护城河（共享waterMat三面）+木桥+岸石芦苇鸭 |
| night-light | 70 | 宫殿塔寺明德门补充灯笼 + 7组点光源（包装updateDayNight昼夜联动） |
| outside | 80 | 城外驿站/水井/里程碑 + 城外树林（原addTree） |

### 素材共享策略

**核心原则**：不重复存储纹理，全部复用共享几何体和材质。
- 所有enhance模块使用共享UNIT_BOX/UNIT_CYL/UNIT_SPHERE/ROOF_UNIT/ROOF_SMALL
- 所有材质使用共享MAT，新材质也按类型共享单一实例（如花卉每色1个材质）
- 不重复创建天空/水面/农田/树木/角楼/垛口/台阶/荷花/灯柱等已有系统
- 新增内容只做原系统缺失部分的补充，并注册碰撞/飞行障碍/可通行区
- 统一使用原系统变量名：sun/ambient/hemi/rim/MAT/scene/renderer

## 操作说明

- **WASD**：移动 · **鼠标/触控**：镜头旋转 · **滚轮/双指**：缩放
- **Shift**：加速 · **E**：交互/拾取诗笺 · **G**：切换移动模式（步行/骑行/飞行）
- **C**：镜头模式 · **N**：昼夜切换 · **M**：静音 · **L**：诗笺集
- **B**：摇铃 · **H**：帮助
