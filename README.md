# 龙游长安 · 盛唐开放世界页游

步行、骑行或乘风飞行，漫游盛唐长安城。

## 特色

### 开放世界
- **108坊** 完整还原唐代长安棋盘格局
- **朱雀大街** 26米宽御道，贯穿南北
- **大明宫** 含元殿+麟德殿，宫阙巍峨
- **东西市** 繁华商业区，酒肆茶坊布庄粮行
- **曲江池** 诗意水景，荷花芦苇亭子小桥

### 视觉质感
- 国风漫剧/电影画风
- ACES电影级色调映射
- PBR真实材质（normal + roughness贴图）
- SAO屏幕环境光遮蔽
- Bloom辉光 + FXAA抗锯齿
- 暖金日光 + 青灰雾霭的国风配色

### 动态氛围
- 🌸 花瓣飘落（桃花/樱花）
- 🐦 飞鸟盘旋
- 🎵 五声音阶环境音景
- 🌤️ 晴/阴/雨天气系统
- 🏮 街道灯笼

### 探索玩法
- 🚶 步行 / 🚲 骑行 / ✈️ 飞行 三种移动模式
- 📍 16个景点（朱雀大街/大明宫/大雁塔/曲江池等）
- 📜 20首唐诗诗笺收集
- 🎬 16个电影级赏景镜头

## 核心建筑精修（本轮新增）

### 主体建筑
- **朱雀大街**：中央御道石板 + 两侧排水沟 + 行道槐阵列
- **大明宫**：丹凤门重檐庑殿顶 + 朱红立柱阵列 + 殿前玉阶 + 斗拱层（坐斗/翘/昂）
- **东西市**：店铺立面 + 朱红招牌 + 带布篷摊位
- **曲江池**：湖岸石板步道 + 四角攒尖亭 + 荷花荷叶
- **城墙**：四面城墙 + 垛口 + 明德门城楼（重檐+门洞）+ 四角角楼
- **大雁塔**：七层楼阁式砖塔（逐层收分+出檐+金属塔刹）
- **小雁塔**：十五层密檐式砖塔（密集出檐+秀丽轮廓）
- **兴庆宫**：花萼相辉楼（重檐+立柱）+ 沉香亭（攒尖顶）+ 牡丹园 + 龙池

### PBR材质库

### 电影级光影

## 技术栈

- **引擎**：Three.js r160
- **渲染**：WebGL2 + 后处理管线
- **批渲染**：InstancedMesh + 空间分区 + LOD
- **天空**：自定义Shader（云层+太阳+星星）
- **材质**：Canvas程序化纹理 + CC0 PBR贴图

## 运行

直接打开 `index.html` 即可（需要HTTP服务器）：

```bash
npx serve .
# 或
python -m http.server 8000
```
