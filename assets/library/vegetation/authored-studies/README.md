生成：`blender -b -t 2 -P tools/build_botanical_studies.py`。不覆盖相邻EZ-Tree原源码、叶片及恢复的12个GLB。

四类各LOD0/1/2：柳树根在地面、主枝上独立悬垂Bezier细枝/弯曲长叶；花树为真实五瓣浅杯花几何，花叶分材质；松树横展枝盘/针簇；街树阔叶簇。统一固定seed、主枝和簇中心，降采样细叶/枝段，不以整树贴片取代三维。没有外部网格或图片，属于本项目原创生成代码；不将原EZ-Tree许可错误套在本目录上。

LOD0三角形：柳22092、花16188、松35664、街11292；全部摘要与每级面数见manifest。叶/瓣是真实小曲面，使用双面材质而非透明矩形。原EZ-Tree alpha裁切仍在组合试片中单独验证。
