# 高精龙原件与用途

`grab3d/cartoon-dragon/` 和 `grab3d/chinese-dragon/` 分别保存**原始约80万三角形、4K贴图的自包含GLB**、原始可编辑Blend、发布者许可、上游manifest和逐文件哈希。来源是 Grab3D，发布者明确披露 Meshy AI 辅助初稿、Blender清理；许可CC0。它们是实际取得的静态雕塑，不能冒称专业手工重拓扑/完整可动画角色。

桌面验收默认选择 **source.glb**，没有减面或降低贴图分辨率。原件不被任何脚本覆盖。

- cartoon-dragon：眼窝、鼻吻、颊部、鳞片细腻，适合观察幼龙脸部；四足坐姿且有翼，不能直接称为认可的无翼小青龙。
- chinese-dragon：角、须、鬃、长躯干可作中国龙结构研究； ornamental盘曲构图，不能直接作可骑车小龙。
- 两者均无骨骼、动作或表情，不能仅靠加载成功就进入生产。

早期 `inspection-lod.glb` 为减面/降图实验，实际查看发现明显裂片/烘焙瑕疵，**已经否决，禁止用作默认或生产模型**。其元数据保留失败状态，生成器默认停止，只有显式诊断标志才运行旧实验。这不是原始源的质量。

在 `tools/model_review.html` 的“高精原始素材”选择器查看原件，支持正侧背俯/灰模。`tools/desktop_source_review_test.py` 验证1920×1200与2560×1600原件，软件渲染只作正确性检查，不能冒充用户电脑帧率。
