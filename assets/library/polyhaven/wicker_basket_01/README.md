# Wicker Basket 01 — Poly Haven CC0

Author: Kuutti Siitonen. Original asset page: https://polyhaven.com/a/wicker_basket_01

Free 8K wicker basket model with hand-woven twine, dark weathered wood tones, tight rectangular weave, braided rim and realistic grain with subtle wear.

Original glTF + binary + all referenced 1k textures have been downloaded and checked against the official API MD5 values. SHA256 values, dimensions and source URLs are in manifest.json. The source is not evidence of Tang date or archaeological provenance. Preserve this provenance if deriving a local GLB.

The bundled source material uses sRGB diffuse/base color, tangent-space OpenGL normal, and packed ARM (R=ambient occlusion, G=roughness, B=metalness). Main runtime use depends on a separately optimized GLB derivative.
