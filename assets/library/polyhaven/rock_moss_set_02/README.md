## 描述
第二套青苔岩石组合，包含多种形态的自然岩石，表面覆盖苔藓。与 rock_moss_set_01 形态互补，用于增加曲江岸边和园林假山的岩石形状多样性。

## 使用说明
- 每个岩石节点独立归零，可分别摆放
- 运行时建议做 LOD 优化，远景使用简化几何
- 苔藓色调需与场景整体湿润感统一
- 不声明为唐代特定石作工艺
