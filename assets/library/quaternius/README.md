# Selected Quaternius assets

Author: Quaternius. The Ultimate Animated Animal Pack author page explicitly identifies CC0; saved HTML and mirror license catalogue are included. Downloaded from a pinned public mirror revision. The mirror MIT license covers its web code, not these models. Newer QAL packs are not adopted.

Original model meshes, bones, skin weights and walking/idle/grazing clips are retained in source.glb. Runtime derivations are produced by tools/prepare_animals.py and recorded separately.
