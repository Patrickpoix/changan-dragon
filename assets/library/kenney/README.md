# Optional Kenney model library

These four CC0 model files are bundled for future evaluation. The game does not load them.

The upstream README inside each subfolder explicitly licenses the included 3D models, sprites and sounds under CC0. Upstream LICENSE.md is the separate game-template software license (MIT), not the source of the asset CC0 grant. The original upstream README and LICENSE are retained.

Preserve Textures/colormap.png beside each model folder. Each GLB uses that relative external image path. The tree models include merged ground tiles and are not standalone tree-node collections. Source revision, original URLs, hashes and mesh counts are in manifest.json.

See docs/ASSET_RESEARCH.md for selection reasons and performance constraints.
