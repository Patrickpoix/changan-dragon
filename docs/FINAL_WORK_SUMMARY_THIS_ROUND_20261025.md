## 二、关键结论

### 引擎选型
- 选定 Three.js r169
- 理由：包体小、生态厚、现有代码零迁移

### 素材现状
- 51个GLB模型
- 224张PBR贴图
- 8张4K HDRI
- 234个音效 + 4首BGM
- 总量约2.3GB

### 核心策略
- 大型建筑走程序化生成路线
- 树木走ez-tree程序化生成
- 水面走jbouny/ocean着色器
- 模型倾向用外部GLB，不自己Blender建模
