# 植被系统详细设计

> 创建时间：2026-10-25

## 唐代长安的植被

### 行道树
- **槐树（国槐）**: 朱雀大街、主干道两侧
- **柳树**: 河边、曲江池畔
- **榆树**: 普通街道

### 园林植物
- **牡丹**: 贵族宅邸、曲江池
- **荷花**: 曲江池、太液池
- **竹子**: 文人宅邸、寺庙
- **梅花**: 冬季景观
- **桃花**: 春季景观

### 寺庙植物
- **古松**: 寺庙庭院
- **银杏**: 大慈恩寺（大雁塔）
- **菩提树**: 唐代长安不常见，用松替代

## 技术方案

### 程序化树木生成
- **ez-tree** (⭐1718): 已选定
- 参数化生成树干、树枝、树叶
- 可生成：槐树、柳树、松树、银杏

### LOD策略
| 距离 | 渲染方式 |
|---|---|
| <20m | 精模树木（1k面） |
| 20-50m | 中模树木（200面） |
| 50-100m | 低模树木（50面） |
| >100m | Billboard树木 |

### InstancedMesh
- 同类树木用InstancedMesh
- 10万棵树 = 1个DrawCall
- 颜色随机变化

## 季节变化

### 春（1-3月）
- 桃花盛开（粉色）
- 柳树发芽（嫩绿）
- 牡丹花苞

### 夏（4-6月）
- 浓绿树叶
- 荷花盛开
- 树荫浓密

### 秋（7-9月）
- 银杏变黄
- 枫叶变红
- 落叶开始

### 冬（10-12月）
- 落叶树光秃
- 松树常绿
- 梅花花苞
- 雪后积雪

---

## 性能优化

- 树木总数：10万+棵
- 全部InstancedMesh合批
- 远距离billboard
- 风动效果：顶点着色器，零CPU开销
- 季节切换：换贴图/换颜色，不换模型
