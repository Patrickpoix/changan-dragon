## 一、项目概述

**龙游长安**是一个等比例复刻唐长安城的开放世界WebGL游戏项目。

- **目标**：《长安三万里》电影质感 + 《对马岛之魂》开放世界水准
- **规模**：84.1平方公里，108坊，朱雀大街长6.9km
- **平台**：Web浏览器（Three.js）
- **主角**：小青龙（可飞行探索全城）
