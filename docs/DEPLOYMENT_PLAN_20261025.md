# 部署方案文档（2026-10-25）

> 项目部署与发布的方案。

---

## 一、部署方式

### GitHub Pages
- **优点**：免费、简单、自动部署
- **缺点**：静态托管，不能太大
- **适合**：Demo/小项目

### Vercel/Netlify
- **优点**：免费、快速、CDN
- **缺点**：静态托管
- **适合**：Demo/小项目

### 自建服务器
- **优点**：完全可控
- **缺点**：需要维护
- **适合**：正式上线

## 二、构建流程

### 构建步骤
```bash
# 1. 安装依赖
npm install

# 2. 构建
npm run build

# 3. 输出到dist/
dist/
├── index.html
├── assets/
│   ├── buildings/
│   ├── characters/
│   └── ...
└── js/
```

### 优化
- 代码压缩
- 树摇(tree-shaking)
- 懒加载
- 资源压缩
