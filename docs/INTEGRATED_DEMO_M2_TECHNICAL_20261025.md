## 1. Demo 内容

- **范围**：1km² 可自由行走片区
- **朱雀大街**：150m宽贯穿
- **平康坊**（东）：娱乐区
- **延寿坊**（西）：胡商区
- **建筑**：950+ 实例化
- **地标**：明德门、大雁塔、牌坊、石狮
- **NPC**：200个（120胡商+80文人）

## 2. 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角 |
| Shift | 奔跑 |
| 数字键1 | 昼夜切换 |
| 数字键2 | 雨切换 |
