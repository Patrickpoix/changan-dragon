# 108坊生成器技术实现（2026-10-25）

> 108坊程序化生成器的技术实现方案。

---

## 一、生成策略

### 三级生成
1. **A类地标**：14个手工精模（大明宫、大雁塔等）
2. **B类坊块**：按类型程序化生成（8类）
3. **C类点缀**：石灯、经幢、牌坊等小物件

### 差异化保证
- 每坊固定seed（mulberry32）
- 按坊类型选择建筑组合
- 不同材质/颜色/植被
- 人群分布不同
- 绝不千篇一律

## 四、生成流程

1. 读取坊列表（108个坊的位置+类型）
2. 对每个坊：
   - 分配seed（固定，保证一致性）
   - 选择建筑组合（按类型）
   - 随机排列（按seed）
   - 分配植被（按类型）
   - 分配NPC（按类型+密度）
3. 输出：chunk数据（500m×500m）
4. 加载时按位置加载对应chunk

---

## 五、技术实现

### 输入
- 坊列表JSON（位置+类型）
- 建筑kit（25个模块化kit）
- 材质库（PBR纹理）
- NPC模板（12阶层variety）

### 输出
- GLB chunk（500m×500m）
- 包含：建筑+植被+装饰
- 带LOD
