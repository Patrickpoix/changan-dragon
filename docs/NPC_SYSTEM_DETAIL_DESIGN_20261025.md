# NPC系统详细设计（2026-10-25）

> 800个NPC，不同阶层、不同行为、不同服饰，让长安城活起来。

---

## 一、NPC规模

### 按区域分布
| 区域 | 人数 | 说明 |
|---|---|---|
| 朱雀大街 | 500 | 峰值，最热闹 |
| 西市 | 300 | 商业繁忙 |
| 东市 | 200 | 商业+文人 |
| 普通坊（每坊） | 50-100 | 居民 |
| 大明宫 | 100 | 守卫+官员 |
| 曲江池 | 150 | 游人 |
| 慈恩寺 | 80 | 僧侣+香客 |
| 全城上限 | 800 | 同时存在 |

---

## 二、NPC类型（12阶层）

1. 高级官员（紫袍）
2. 中级官员（绯袍）
3. 低级官员（绿/青袍）
4. 文人书生（襕衫）
5. 贵族妇女（华丽襦裙）
6. 普通妇女（素色襦裙）
7. 士兵（明光铠）
8. 僧侣（袈裟）
9. 胡商（翻领袍）
10. 平民百姓（短褐）
11. 手艺人（短衣）
12. 儿童（童装）

---

## 三、行为系统

### 行为类型
| 行为 | 说明 |
|---|---|
| 行走 | 从A点到B点 |
| 站立 | 站在某处 |
| 交谈 | 两人面对面交谈 |
| 工作 | 打铁/织布/卖货 |
| 购物 | 在店铺前挑选 |
| 吃饭 | 在酒楼就餐 |
| 烧香 | 在寺庙拜佛 |
| 骑马 | 骑马行走 |

### 状态机
- 出生 → 选择目标 → 行走 → 到达 → 执行行为 → 离开 → 消失

---

## 四、技术实现

### 性能优化
- 1个骨架 + palette换色
- InstancedMesh合批
- A*寻路（网格导航）
- RVO避障
- >80m用billboard impostor

### 动画
- 待机idle
- 行走walk
- 跑步run
- 骑马ride
- 其他动作（可扩展）

---

## 五、时间变化

### 白天（6:00-18:00）
- 人多热闹
- 商业繁忙
- 行人匆匆

### 夜晚（18:00-6:00）
- 人少安静
- 只有娱乐区热闹
- 宵禁（坊门关闭）

### 特殊时刻
- 上元灯节：全城灯笼，万人空巷
- 庙会：寺庙周围人多
- 科举：文人聚集

---

## 六、差异化保证

### 按坊类型分配人群
- 官署区：官员+士兵多
- 贵族区：贵族+仆人多
- 平民区：百姓+手艺人多
- 寺庙区：僧侣+香客多
- 商业区：商贩+顾客+胡商多
- 娱乐区：文人+妓女+食客多
- 园林区：游人+仕女+文人多
- 作坊区：工匠+学徒多
