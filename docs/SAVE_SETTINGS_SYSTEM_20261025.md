# 存档与设置系统设计

> 创建时间：2026-10-25

---

## 存档系统

### 存档位置
- localStorage（浏览器本地存储）
- 不需要服务器
- 玩家自己的浏览器保存

### 存档内容
```json
{
  "playerPosition": { "x": 100, "y": 0, "z": 200 },
  "playerForm": "dragon",
  "gameTime": 12.5,
  "weather": "sunny",
  "quests": [...],
  "collected": [...],
  "discoveredPlaces": [...],
  "settings": {
    "volume": 0.8,
    "quality": "high",
    "invertY": false
  }
}
```

### 自动存档
- 每5分钟自动存
- 切换场景时存
- 退出时存

### 手动存档
- 玩家可随时手动存
- 可存多个槽位

## 设置系统

### 画质设置
| 选项 | 说明 |
|---|---|
| 自动 | 根据性能自动调整 |
| 高 | 全部后处理 + 高画质 |
| 中 | Bloom + 色彩分级 |
| 低 | 只色彩分级 |
| 移动端 | 关闭后处理 |

### 音量设置
| 选项 | 说明 |
|---|---|
| 主音量 | 总音量 |
| BGM音量 | 背景音乐 |
| SFX音量 | 音效 |

### 控制设置
| 选项 | 说明 |
|---|---|
| 反转Y轴 | 开关 |
| 鼠标灵敏度 | 可调 |
| 按键自定义 | 后续版本 |

### 显示设置
| 选项 | 说明 |
|---|---|
| 全屏 | 开关 |
| FOV | 视野角度 |
| 显示FPS | 开关 |

---

## 性能自动调整
- 帧率<30fps时自动降画质
- 帧率<20fps时关闭后处理
- 帧率<15fps时减少NPC
- 帧率>60fps时可升画质
