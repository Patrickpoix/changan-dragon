# 长安法律与刑罚系统设计

> 创建时间：2026-10-25

---

## 唐代法律

### 唐律疏议
- **地位**: 中国现存最完整的古代法典
- **内容**: 12篇，502条
- **原则**: 礼法合一，德主刑辅

### 刑罚等级
| 等级 | 刑罚 |
|---|---|
| 笞 | 用竹板打（10-50下） |
| 杖 | 用木棍打（60-100下） |
| 徒 | 劳役（1-3年） |
| 流 | 流放（2000-3000里） |
| 死 | 绞刑/斩刑 |

### 大理寺
- **最高法院**
- 审理重大案件

### 刑部
- **司法行政**
- 制定法律

### 御史台
- **监察**
- 监督官员

## 玩家法律系统
- **犯罪**: 偷窃、伤人、杀人
- **通缉**: 犯罪后被通缉
- **被捕**: 被抓后受审
- **刑罚**: 根据罪行判刑
- **越狱**: 可以越狱（高风险）
