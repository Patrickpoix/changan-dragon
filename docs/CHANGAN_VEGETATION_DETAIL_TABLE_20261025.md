## 季节变化
| 季节 | 主要变化 |
|---|---|
| 春 | 桃花盛开、柳树发芽、牡丹 |
| 夏 | 浓绿树荫、荷花盛开 |
| 秋 | 银杏金黄、枫叶红 |
| 冬 | 落叶光秃、松常绿 |

*植被是城市生机的体现，不同区域要有特色。*
