## 一、压缩工具

### 1. zipoly（4星）
- 地址：https://github.com/v-plugin/zipoly
- 描述：跨平台3D模型压缩优化桌面工具
- 特点：Draco/Meshopt压缩最高缩减90%、KTX2纹理、7种格式互转、3D查看器、批量处理
- 平台：Windows/Linux/macOS
- 价格：免费版永久可用

### 2. blender-mcp（5星）
- 地址：https://github.com/nirholas/blender-mcp
- 描述：AI agent驱动Blender
- 特点：格式转换、Draco/Meshopt压缩、渲染预览

### 3. compress-glb
- 地址：https://github.com/mpoapostolis/compress-glb
- 描述：CLI工具
- 特点：Draco+meshoptimizer+纹理优化，4级压缩，批量模式
