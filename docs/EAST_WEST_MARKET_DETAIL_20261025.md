# 东西两市详细设计

> 创建时间：2026-10-25

---

## 历史背景
唐代长安有两个市场：东市和西市。
- **东市**: 靠近贵族居住区，高档奢侈品消费
- **西市**: 靠近城门，国际贸易，胡商云集

---

## 东市（高档商业区）

### 位置
- 长安城东部，靠近兴庆宫和贵族宅邸
- 约1000m × 900m

### 建筑风格
- 两层楼阁，精致门面
- 黑瓦白墙，雕梁画栋
- 招牌幌子精致
- 街道整洁

### 业态
| 店铺类型 | 商品 |
|---|---|
| 绸缎庄 | 高级丝织品 |
| 珠宝店 | 珍珠玛瑙 |
| 酒楼 | 高档宴席 |
| 茶馆 | 文人雅集 |
| 香药铺 | 香料药材 |
| 文房四宝 | 笔墨纸砚 |

### 人物
- 官员、富商、文人
- 漂亮的店伙计
- 文人墨客

### 氛围
- 相对安静、高雅
- 顾客不多但消费高
- 音乐声从酒楼传出

---

## 西市（国际贸易区）

### 位置
- 长安城西部，靠近金光门
- 约1000m × 900m

### 建筑风格
- 单层摊位为主，拥挤热闹
- 灰瓦土墙，简陋但密集
- 各种语言的招牌
- 街道杂乱

### 业态
| 店铺类型 | 商品 |
|---|---|
| 胡饼店 | 西域面食 |
| 波斯邸 | 波斯珍宝 |
| 骆驼队 | 运输商队 |
| 皮毛店 | 皮毛制品 |
| 牲畜市场 | 马、牛、骆驼 |
| 酒肆 | 胡人开的酒馆 |
| 卜卦摊 | 西域术士 |

### 人物
- **粟特商人**: 深目高鼻，翻领窄袖袍，蹀躞带
- **波斯人**: 长须长袍
- **昆仑奴**: 深色皮肤，壮汉
- **日本遣唐使**: 日本服饰
- **新罗留学生**: 朝鲜服饰
- **各种小贩**: 叫卖声

### 氛围
- 非常热闹拥挤
- 多语言混杂
- 骆驼叫声、讨价还价声
- 异域风情浓厚

---

## 东西市对比

| 维度 | 东市 | 西市 |
|---|---|---|
| 定位 | 高档消费 | 国际贸易 |
| 建筑 | 精致两层楼阁 | 简陋单层摊位 |
| 顾客 | 官宦富商 | 各国商人 |
| 商品 | 奢侈品 | 杂货+西域特产 |
| 氛围 | 安静高雅 | 热闹拥挤 |
| 颜色 | 黑白素雅 | 多彩杂乱 |
| NPC密度 | 中 | 高 |
