## 一、唐代社会阶层与NPC分类

### 官员阶层
| 品级 | 服色 | 头饰 | 特征 |
|---|---|---|---|
| 三品以上 | 紫色 | 幞头 | 最高级官员 |
| 四品 | 深绯 | 幞头 | 高级官员 |
| 五品 | 浅绯 | 幞头 | 中级官员 |
| 六品 | 深绿 | 幞头 | 中下级官员 |
| 七品 | 浅绿 | 幞头 | 县级官员 |
| 八品 | 深青 | 幞头 | 低级官员 |
| 九品 | 浅青 | 幞头 | 最低级官员 |

**服色制度（品色服）**：
- 这是唐代最核心的服饰等级制度
- 看衣服颜色就能知道品级
- 我们可以用这个快速区分NPC身份

## 三、NPC生成技术方案

### 基础骨骼方案
我们用现有的Xbot/Soldier骨骼作为基础，通过换贴图和调色来产生不同阶层的variety。

### Palette Map 方案
```javascript
// 一个骨骼模型，多个调色板
const NPCVariety = {
  // 官员系列
  official_purple: {
    robe: 0x660099,  // 三品紫
    hat: 0x222222,   // 幞头
    skin: 0xf0cfb5
  },
  official_red: {
    robe: 0xcc0000,  // 四品深绯
    hat: 0x222222
  },
  official_green: {
    robe: 0x006600,  // 六品深绿
    hat: 0x222222
  },
  
  // 文人
  scholar_white: {
    robe: 0xeeeeee,
    hat: 0x333333
  },
  
  // 女性
  lady_pink: {
    robe: 0xffb7c5,
    hair: 0x222222
  },
  
  // 胡商
  hu_merchant: {
    robe: 0x8b4513,  // 翻领袍
    skin: 0xc8956a   // 较深肤色
  },
  
  // 昆仑奴
  kunlun: {
    robe: 0x4a3224,
    skin: 0x4a3224   // 深色皮肤
  }
}
```

## 四、动画系统

### 基础动画clip
- idle（待机）
- walk（走路）
- run（跑步）
- sit（坐，可选）

### 按阶层差异化
- 官员：走路慢，端正
- 文人：走路斯文
- 商贩：走路快，忙碌
- 歌女：走路轻盈
- 士兵：走路整齐
