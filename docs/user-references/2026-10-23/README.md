# 用户补回的旧会话参考

三张JPEG原件逐字节归档，来源和SHA256见manifest.json，不覆盖现有PNG概念与任何恢复素材。

- material-contact：七组真实材质候选的联系表，对应现有production-materials，不是新贴图来源。
- people-study：店主、织物商、商旅、劳动者、文士的整体/背面/表情参考。重点是连续脸形、眉眼口鼻、肩颈关系、真实剪裁、布料厚度与层叠；不是等宽筒袍加球头。发式、服装年代、花纹和各视图不一致仍需核对，不能当精确唐服工程图。
- timber-shop-study：单层铺面、双层楼店、完整侧后院落及剖开室内参考。重点是低阔有重量的瓦顶、柱梁承托、侧后窗门、院墙接口、楼梯、廊道和生活空间。不同小图不一定共享同一结构，正式三维必须同源，不能照图拼出互相矛盾的房子。

用户再次明确：目标是《长安三万里》为主、《大理寺日志》辅助的电影国风，以及类似3A游戏的沉浸式质感与可信感。小龙可爱不意味着城市、人物、布料和光影都做成简单卡通。图像只用于设计，不作为可游玩的背景、人物贴片或已完成三维资产。
