### 3. 音效（SFX）

#### 动作音效
- 脚步：石板路/泥土路/草地
- 开门：木门吱呀
- 关门：砰
- 拾取：叮
- 对话开始：轻提示音

#### 互动音效
- NPC对话：语音气泡音
- 交易：铜钱声
- 任务完成：欢快旋律
- 受伤：闷响

## 技术实现

### AudioManager
```javascript
class AudioManager {
  // BGM管理
  playBGM(trackName, fadeTime)
  stopBGM(fadeTime)
  
  // 环境音
  playAmbient(soundName, position)
  
  // 3D音效
  playSFX(soundName, position, volume)
  
  // 音量控制
  setMasterVolume(v)
  setBGMVolume(v)
  setSFXVolume(v)
}
```

### 3D PositionalAudio
- Three.js内置PositionalAudio
- 声音随距离衰减
- 近大远小
- 左右声道定位

### 音频池
- 预加载常用音效
- 并发声道：32个
- 避免重复播放同一音效

## 性能优化
- 音频内存预算：<256MB
- 同一时间最多32个并发声道
- 远处环境音自动降低音量
- 静音时暂停BGM
