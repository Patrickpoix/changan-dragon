## 二、核心技术突破

### 1. 大型建筑解决方案
- **forbidden-city-3d**（MIT）：程序化生成332个故宫建筑，斗拱屋顶参数化
- **taihe-hall**：Three.js太和殿程序化生成，PBR材质参考
- 结论：大型建筑走程序化生成路线，不依赖外部模型

### 2. 动态水面解决方案
- **jbouny/ocean**（803 stars）：经典水面着色器，反射+折射+波浪
- **jeantimex/threejs-water**：光线追踪反射+焦散+交互水面
- **caustic-volume**：实时水面焦散效果
- 结论：曲江池用jbouny/ocean+焦散叠加

### 3. 树木生成解决方案
- **ez-tree**（1717 stars）：程序化树木生成器，LOD+风动动画+GLB导出
- 可生成：垂柳、松树、桃花树、行道树等唐代园林树木
- 可替换自定义4K树皮材质

### 4. 角色与道具资源
- **three.ws**：免费CC0道具+绑定角色+动作库，无需账号
- 可直接下载GLB，丰富NPC和市集道具
