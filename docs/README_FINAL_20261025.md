# 龙游长安

**唐长安全比例开放世界WebGL项目**

---

## 项目简介

龙游长安是一个开源的唐长安全比例开放世界项目，目标是用WebGL技术在浏览器中复刻盛唐长安城，让玩家可以自由探索这座当时世界上最大的城市。

- **城市面积**: 84.1 km²（真实尺寸1:1复刻）
- **坊数**: 108坊
- **引擎**: Three.js r169
- **风格**: 国漫电影质感
- **许可证**: 开源免费

---

## 核心特色

- **真实尺寸**: 按考古数据1:1复刻长安城
