# 长安植被详细分布

> 创建时间：2026-10-25

---

## 行道树

### 朱雀大街
- **树种**: 国槐
- **排列**: 两侧整齐排列，间距10米
- **形态**: 高大乔木，树冠茂密
- **数量**: 约1400棵（两侧各700）

### 其他主干道
- **树种**: 槐树、榆树
- **排列**: 两侧排列
- **数量**: 约2000棵

---

## 园林植物

### 贵族宅邸
- **牡丹**: 庭院种植
- **竹子**: 围墙边
- **垂柳**: 水池边
- **芭蕉**: 庭院角落

### 曲江池
- **垂柳**: 沿湖种植
- **荷花**: 水面种植
- **芦苇**: 岸边
- **桃树**: 春季赏花

### 大明宫
- **古松**: 宫殿庭院
- **梧桐**: 大道旁
- **牡丹**: 太液池畔

## 平民坊
- **枣树**: 坊内水井旁
- **柳树**: 河边

## 季节变化
| 季节 | 主要变化 |
|---|---|
| 春 | 桃花盛开、柳树发芽 |
| 夏 | 浓绿树荫、荷花盛开 |
| 秋 | 银杏金黄、枫叶红 |
| 冬 | 落叶光秃、松常绿 |
