# 唐长安108坊功能分区总表（2026-10-25）

> 基于考古研究，将108坊按功能分类，每类有不同的建筑风格、人群和业态。

---

## 一、按功能分类

### 1. 官署区（约15坊）
- **位置**：皇城周围、朱雀大街两侧
- **特征**：规整、宏伟、守卫
- **建筑**：官署衙门、官邸
- **人群**：官员、守卫、差役

### 2. 贵族住宅区（约20坊）
- **位置**：东城、城北、靠近大明宫
- **特征**：高大门楼、大院落、朱红门
- **建筑**：贵族宅第、王府
- **人群**：贵族、家眷、仆人

### 3. 平民里坊（约40坊）
- **位置**：西城、南城、普通区域
- **特征**：低矮民居、生活气息
- **建筑**：普通民居、小作坊
- **人群**：百姓、手艺人、小商贩

### 4. 寺庙区（约10坊）
- **位置**：全城分散
- **特征**：庄严、安静、香火
- **建筑**：寺院、道观、佛塔
- **人群**：僧侣、道士、香客

### 5. 商业区（2坊+周边）
- **西市、东市**
- **特征**：热闹、喧闹、商铺密集
- **建筑**：店铺、酒楼、仓库
- **人群**：商贩、顾客、胡商

### 6. 娱乐区（约5坊）
- **位置**：平康坊等
- **特征**：酒楼、歌楼、夜晚热闹
- **建筑**：酒楼、歌馆、妓院
- **人群**：文人、官员、妓女、食客

### 7. 园林风景区（约8坊）
- **位置**：曲江池周围、兴庆宫周围
- **特征**：花树、水面、亭台
- **建筑**：园林、别墅、亭台
- **人群**：游人、文人、仕女

### 8. 作坊区（约10坊）
- **位置**：城外边缘、坊内角落
- **特征**：烟囱、作坊、货物堆放
- **建筑**：作坊、仓库、工匠住宅
- **人群**：工匠、作坊主、学徒

## 五、生成器使用方法

1. 每坊分配一个类型（8类之一）
2. 按类型选择建筑参数（高度/瓦色/墙色/大门）
3. 按类型选择人群参数（人群/密度/颜色/活动）
4. 按类型选择植被密度
5. 每坊固定seed，保证一致性
6. A类地标手工精模，不参与生成
