# 碰撞检测与物理系统设计

> 创建时间：2026-10-25

---

## 物理需求
开放世界不需要复杂物理，只需要：
1. 玩家不穿墙
2. 玩家不掉出地图
3. NPC之间不重叠

---

## 碰撞方案

### 简化碰撞（不使用物理引擎）
- 用AABB包围盒做碰撞
- 建筑是静态碰撞体
- 玩家是圆形碰撞体
- 简单检测：玩家位置 vs 建筑包围盒

### 为什么不用Ammo.js/ cannon.js
- 物理引擎太重（几MB）
- 开放世界只需要简单碰撞
- 用代码手写碰撞更轻量

---

## 碰撞层级

| 层级 | 用途 |
|---|---|
| 世界边界 | 地图四周，不能走出长安城 |
| 建筑碰撞 | 不能穿进建筑里 |
| 地面高度 | 不能掉出地面 |
| NPC碰撞 | NPC之间不重叠（RVO避障） |

---

## 实现方式

### 静态碰撞数据
- 每个chunk生成时，同时生成碰撞体列表
- 碰撞体：AABB盒子（位置+尺寸）
- 存储在chunk数据里

### 玩家碰撞检测
```
玩家位置 -> 检查附近建筑包围盒
如果玩家在建筑内 -> 推回到建筑外
```

### 高度检测
- 地面是平面（y=0）
- 玩家y位置 = 地面高度
- 飞行时y自由变化

---

## NPC避障（RVO）
- Reciprocal Velocity Obstacles
- 每个NPC预测其他NPC的位置
- 调整自己的速度避免碰撞
- 简单实现：NPC之间保持最小距离

---

## 性能优化
- 只检测玩家周围50m的建筑碰撞
- 远处建筑不检测
- 碰撞体用简化盒子（不用精确模型）

---

*物理越简单越好，开放世界不需要真实物理。*
