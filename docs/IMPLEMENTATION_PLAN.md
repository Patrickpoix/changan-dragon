## 美术与空间方向

参考 `art-direction.png` 和原有 `../ref_changan.jpg`：朱红木构、青灰瓦面、米暖石基、玉绿色小龙、暖日光与空气透视。图像是美术方向参考，实际游戏完全由可编辑立体网格渲染；不把参考图、建筑立绘或角色精灵充当三维场景。唐长安为艺术化缩尺世界，不声称考古复原，木自行车和小龙属于幻想设定。

- 主体：低阔重檐、舒展曲檐、层叠斗拱、木柱和窗棂；宫阙依靠台基、尺度和空间序列体现宏伟。
- 近景：屋檐、布棚、货架与货物、行人、商贩、石栏、树木和灯笼；保留通行空间。
- 角色：小龙的眼睛、双角、腹部、围巾与尾部都保留真实曲面与动画。
- 色彩：深玉色半透明 HUD、暖白文字、少量金色选中态；避免整片霓虹青瓦和清代黄瓦的视觉混淆。
- 镜头：默认第三人称自由探索；侧拍、鸟瞰、环游和无 HUD 的电影赏景补充欣赏建筑。

## 模块与实施顺序

1. **资源与引擎**：联网核对可用素材与授权；保留本地 Three.js。原包未上传时使用有授权与来源记录的独立兼容包，原包上传后优先加载。没有运行时联网依赖。
2. **启动与交互**：修复脚本依赖顺序；补全步行/骑行/飞行、景点、升降和赏景控件；修复键盘、摇杆、模态框、手机横屏与镜头碰撞。
3. **建筑与地形**：让宫门实际可穿行、桥面实际连续；统一旋转店铺的位置变换，补全塔、墙和殿宇的飞行避障高度；提升街景与屋面细节。
4. **材质与渲染**：分离误共享的材质；为空间分区的实例批次计算边界并裁剪；限制移动端像素比和阴影负担。保留真实曲面，不以降低建筑为平面换取性能。
5. **验收与后续交接**：用实际浏览器验证启动、所有移动方式、景点、镜头、昼夜、赏景、拾取与存档；检查桌面、横屏手机与竖屏。记录真实观察，区分未上传资源、代码问题和已通过的功能。

## 控件和布局清单

顶部保留品牌、景点、赏景、昼夜、声音和帮助；地图靠边缩小。底部中央为步行/骑行/飞行三态，左侧摇杆，右侧镜头与加速；飞行时显示升降和高度。电影模式收起日常 HUD，保留场景名、前后景、暂停、留影与退出。诗笺为可选收集，不阻碍漫游。横屏优先，竖屏给予不阻断操作的提示。

## 性能和验证边界

基线静态几何审查约 494 万三角形（不含角色与阴影额外绘制），并非实测帧率。优先做空间批次和小构件简化，再依据浏览器渲染统计调整。无真实手机硬件时只能声称手机尺寸的 Chromium/WebGL 验证，不能声称 iOS/Android 真机或电影制作级画质验收。素材选用及许可见 `ASSET_RESEARCH.md`。
