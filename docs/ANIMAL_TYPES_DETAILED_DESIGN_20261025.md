# 动物类型详细设计（2026-10-25）

> 长安城里的各种动物详细规格。

---

## 一、大型动物

### 马
- **大小**：高1.5m，长2m
- **颜色**：棕/白/黑
- **用途**：骑马/拉车
- **分布**：全城街道
- **动画**：走/跑/站
- **已有**：马模型1个

### 骆驼
- **大小**：高2m，长2.5m
- **颜色**：棕黄
- **用途**：西市胡商驼队
- **分布**：西市最多
- **动画**：走/站/跪
- **缺口**：需要补充

### 牛
- **大小**：高1.4m，长2m
- **颜色**：黄/黑
- **用途**：拉牛车/耕地
- **分布**：平民坊/郊区
- **动画**：走/站
- **缺口**：需要补充

## 二、中小型动物

### 驴
- **大小**：高1.2m，长1.8m
- **颜色**：灰
- **用途**：平民代步/驮货
- **分布**：平民坊

### 狗
- **大小**：高0.5m，长0.8m
- **颜色**：黄/黑/花
- **用途**：看家/闲逛
- **分布**：平民坊/门口
- **动画**：走/跑/坐/吠

### 鸡
- **大小**：高0.4m
- **颜色**：黄/花
- **用途**：家禽
- **分布**：平民坊院子
- **动画**：走/啄食
- **缺口**：需要补充

- **用途**：天空点缀
- **分布**：全城天空
- **动画**：飞/落

- **分布**：曲江池

- **缺口**：需要补充
