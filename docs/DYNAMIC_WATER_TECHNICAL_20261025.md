# 动态水面 — 技术实现文档

> 版本：v1.0
> 状态：🔄 设计完成，待集成

---

## 1. 技术方案

基于 jbouny/ocean 着色器方案，适配 Three.js r169。

### 1.1 核心特性
- Gerstner 波（真实波浪形状）
- 菲涅尔反射
- 深度颜色渐变
- 阳光波光
- 岸边泡沫
- 船桨尾波（待实现）

---

## 2. 应用场景

| 场景 | 水面类型 |
|---|---|
| 曲江池 | 开阔湖面 |
| 太液池（大明宫） | 皇家园林湖 |
| 护城河 | 环城河道 |
| 金水河 | 城内水系 |
| 水井/池塘 | 小水面 |

---

## 3. 着色器参数

| 参数 | 值 | 说明 |
|---|---|---|
| 波浪高度 | 0.3m | 唐城内水面较平静 |
| 波浪频率 | 0.5 | 慢速 |
| 透明度 | 0.8 | 半透明 |
| 反射率 | 0.5 | 中等 |
| 水深颜色 | 深青绿 | |
| 浅水颜色 | 浅蓝绿 | |

---

## 4. 性能优化
- 水面用 PlaneGeometry 分段（128×128）
- 仅在水面区域渲染（不铺满全城）
- 远处水面用简化 shader
- 反射用 CubeCamera（仅近距离）
