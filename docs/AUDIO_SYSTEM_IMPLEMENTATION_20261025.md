# 音效系统技术实现（2026-10-25）

> 空间音效、环境音、背景音乐的技术方案。

---

## 一、环境音

### 按区域
| 区域 | 主要环境音 |
|---|---|
| 朱雀大街 | 行人脚步声、马车声、交谈声 |
| 西市 | 叫卖声、讨价还价、驼铃声、食物烹饪 |
| 东市 | 轻柔交谈、茶水声、字画展开、算盘声 |
| 普通坊 | 鸡鸣狗吠、邻里交谈、孩子嬉闹、井水声 |
| 慈恩寺 | 钟声、诵经声、木鱼声、风铃 |
| 曲江池 | 水波声、桨声、鸟鸣、远处钟声 |
| 大明宫 | 安静肃穆、脚步声、风吹铁马 |

### 按天气
- 晴天：轻微风声、鸟鸣
- 阴天：更安静、风声小
- 雨天：雨声、淅沥声
- 雪天：极安静、无声

## 四、技术实现

### Web Audio API
- 空间音效（3D定位）
- 音量衰减（距离衰减）
- 环境音循环
- 音乐淡入淡出

### 优化
- 音频懒加载
- 只播放附近的音效
- 避免同时太多音效
