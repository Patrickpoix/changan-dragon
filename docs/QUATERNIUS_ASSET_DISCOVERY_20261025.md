## 重要资源

### 1. quaternius-showcase (trebeljahr, ⭐8)
- URL: https://github.com/trebeljahr/quaternius-showcase
- **在线浏览所有Quaternius CC0低多边形包，可单独下载GLB**
- 网站: https://quaternius.trebeljahr.com
- 技术: React Three Fiber + Next.js
- **价值**: 直接浏览下载单个模型，不用整包下载

### 2. gltf-medieval-village-megakit (J-Ponzo, ⭐1)
- URL: https://github.com/J-Ponzo/gltf-medieval-village-megakit
- Quaternius中世纪村庄MegaKit的glTF版本
- **完整村庄建筑套件**：房屋、城墙、塔、道路等
- CC0免费
- **价值**: 虽然是欧式中世纪，但模块化建筑方法可参考

### 3. gltf-universal-animation-library (J-Ponzo, ⭐2)
- URL: https://github.com/J-Ponzo/gltf-universal-animation-library
- Quaternius通用动画库的glTF版本
- 免费版（itch.io上的标准版）
- **价值**: NPC动画（走、跑、坐、挥臂等）

### 4. game-models (NoLimitNexus, ⭐1)
- URL: https://github.com/NoLimitNexus/game-models
- 免费CC0动画角色（Quaternius + KayKit）
- Web-ready GLB格式
- 带在线viewer
