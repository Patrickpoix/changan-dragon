# 长安项目技术架构总结

> 创建时间：2026-10-25

---

## 技术栈

### 核心
- **引擎**: Three.js r169
- **构建**: Vite
- **语言**: JavaScript (ES6+)

### 关键库
- DRACOLoader（几何压缩）
- MeshoptDecoder
- KTX2Loader（纹理压缩）

---

## 系统架构

### 渲染层
- WebGL渲染器
- EffectComposer后处理
- LOD系统
- InstancedMesh合批

### 世界层
- Chunk流加载（500m×500m，360块）
- 108坊程序化生成器
- 建筑模块化kit
- 植被系统（ez-tree）

### 系统层
- NPC群集系统（RVO避障）
- 昼夜天气系统
- 音频系统
- 水面系统（jbouny/ocean）

### 玩家层
- 小青龙角色
- 第三人称控制
- 变身系统（龙/人）

---
