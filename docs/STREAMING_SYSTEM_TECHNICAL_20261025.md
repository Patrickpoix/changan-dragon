# 流加载系统 — 技术实现文档

> 版本：v1.0
> 状态：✅ POC 验证通过

---

## 1. 分块策略

### 1.1 Chunk 划分
- 尺寸：500m × 500m
- 总数：360 chunks（覆盖84.1km²）
- 原点：西南角
- 坐标系：X东 Z北，1 unit = 1m

### 1.2 加载策略
| 范围 | 行为 |
|---|---|
| 3×3 chunk 常驻 | 玩家周围9个chunk始终加载 |
| 7×7 chunk 预加载 | 提前加载周边49个 |
| >7×7 | 卸载（双缓冲） |

---

## 2. 加载流程

```
玩家移动
  ↓
计算当前chunk坐标
  ↓
检查3×3范围内哪些chunk已加载
  ↓
缺失的chunk → 请求加载（JSON+GLB）
  ↓
远离的chunk → 标记卸载
  ↓
双缓冲：加载完成后切换，旧chunk延迟销毁
```

## 3. LOD 分级

| 距离 | 模型精度 |
|---|---|
| <100m | 精模（LOD0） |
| 100-300m | 中模（LOD1） |
| 300-800m | Billboard（LOD2） |
