# 商店系统设计（2026-10-25）

> 商店/交易系统的设计方案。

---

## 一、货币

### 铜钱
- 基础货币
- 日常交易
- 单位：文/贯(1000文=1贯)

---

## 二、商店类型

### 西市（国际贸易）
- **商品**：香料、珠宝、玻璃器、药材
- **特点**：胡商经营，价格较高，货物稀有
- **人群**：胡人、富商

### 东市（高档商业）
- **商品**：绢帛、书画、文房、茶酒
- **特点**：官宦消费，文化气息
- **人群**：文人、官眷

### 普通坊（日用品）
- **商品**：粮食、布匹、工具、杂货
- **特点**：平民日常，价格实惠
- **人群**：百姓

## 四、交易流程

### 买东西
1. 与商人对话
2. 打开商店界面
3. 选择商品
4. 确认购买
5. 扣铜钱，加物品

### 卖东西
1. 打开商店界面
2. 切换到出售
3. 选择物品
4. 确认出售
5. 加铜钱，减物品

## 五、技术实现

### 商店管理器
```javascript
class ShopManager {
  constructor() {
    this.shops = {};
  }

  openShop(shopId) {
    const shop = this.shops[shopId];
    // 打开商店UI
    this.showShopUI(shop);
  }

  buyItem(shopId, itemId) {
    const shop = this.shops[shopId];
    const item = shop.items.find(i => i.id === itemId);

    }
  }

  sellItem(itemId) {
    const item = player.inventory.find(i => i.id === itemId);
    if (item) {
      player.coins += Math.floor(item.price * 0.5);  // 卖价是买价一半
      player.inventory = player.inventory.filter(i => i.id !== itemId);
    }
  }
}
```
