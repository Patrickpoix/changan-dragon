# 本地开发环境搭建

> 更新时间：2026-10-25

---

## 环境要求
- Node.js 18+
- npm
- Git

## 克隆仓库
```bash
git clone https://github.com/Patrickpoix/changan-dragon.git
cd changan-dragon
```

## 安装依赖
```bash
npm install
```

## 运行 demo
```bash
cd new-assets/integrated-demo
npm run dev
```

## 构建
```bash
npm run build
```
