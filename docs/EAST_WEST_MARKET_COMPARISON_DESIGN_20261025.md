# 东市与西市详细设计对比

> 设计文档版本：v1.0
> 日期：2026-10-25
> 核心：两市风格、业态、人群必须明显不同

---

## 一、总体对比

| 维度 | 东市 | 西市 |
|---|---|---|
| 位置 | 城东部（靠近贵族区） | 城西部（靠近城门） |
| 面积 | 约1平方公里 | 约1平方公里 |
| 定位 | 奢侈品/高档消费 | 国际贸易/大众商业 |
| 顾客 | 贵族、高官 | 胡商、百姓 |
| 建筑风格 | 华丽、规整 | 繁忙、杂乱 |
| 人流量 | 中等 | 极高 |

---

## 二、东市详细设计

### 定位
- 服务于周边贵族宅邸
- 奢侈品、高档商品
- 官宦消费场所

### 业态
| 行业 | 占比 | 说明 |
|---|---|---|
| 丝绸锦绣 | 25% | 高档绫罗绸缎 |
| 珠宝玉器 | 20% | 奢侈品 |
| 酒楼茶肆 | 20% | 高档消费 |
| 金银器 | 15% |
| 香料 | 10% |
| 其他 | 10% |

### 建筑风格
- 商铺面宽：8-12m
- 层数：1-2层
- 装饰：华丽，彩楼欢门
- 招牌：精致，金字牌匾
- 街道：宽阔，整洁

### 人群
| 人群 | 占比 |
|---|---|
| 官员贵族 | 30% |
| 大商人 | 20% |
| 仆人随从 | 30% |
| 普通顾客 | 20% |

---

## 三、西市详细设计

### 定位
- 国际贸易中心
- 胡商云集
- 大众消费市场

### 业态
| 行业 | 占比 | 说明 |
|---|---|---|
| 胡商店铺 | 30% | 波斯、粟特商品 |
| 粮食杂货 | 20% | 大众商品 |
| 马匹交易 | 15% | 西北马 |
| 皮毛 | 10% |
| 酒肆胡姬 | 10% | 西域风情 |
| 饮食店 | 10% |
| 其他 | 5% |

### 建筑风格
- 商铺面宽：6-10m（更小）
- 层数：1层为主
- 装饰：简单实用
- 招牌：异域风格
- 街道：拥挤，繁忙
- 布篷摊位多

### 人群
| 人群 | 占比 |
|---|---|
| 胡商 | 40% |
| 本地商人 | 20% |
| 百姓顾客 | 25% |
| 搬运工 | 10% |
| 外国水手/使节 | 5% |

## 四、视觉差异要点

### 建筑
| 维度 | 东市 | 西市 |
|---|---|---|
| 屋顶颜色 | 深灰（官式） | 多样（杂乱） |
| 墙面 | 粉白墙 | 木构为主 |
| 招牌 | 精致金字 | 布幡幌子 |
| 灯笼 | 少，精致 | 多，杂乱 |

### 植被
- 东市：整齐的槐树行道树
- 西市：几乎没有树，拥挤

### 声音氛围
- 东市：安静，低声交谈
- 西市：嘈杂，叫卖声，胡语

## 五、程序化生成参数

### 东市参数
```javascript
{
  shopWidth: 10,  // 商铺面宽
  buildingStories: 2,  // 层数
  decorationLevel: 'high',  // 装饰密度
  crowdDensity: 0.5,  // 人群密度
  peopleTypes: ['official', 'noble', 'rich_merchant'],
  treeSpacing: 50,  // 行道树间距
  stallDensity: 0.1  // 摊位密度
}
```

### 西市参数
```javascript
{
  shopWidth: 7,  // 商铺面宽
  buildingStories: 1,  // 层数
  decorationLevel: 'low',  // 装饰密度
  crowdDensity: 1.0,  // 人群密度（最高）
  peopleTypes: ['hu_merchant', 'local_trader', 'worker', 'commoner'],
  treeSpacing: 200,  // 行道树很少
  stallDensity: 0.8  // 摊位密度高
}
```
