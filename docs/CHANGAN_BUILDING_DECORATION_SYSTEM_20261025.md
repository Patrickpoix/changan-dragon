# 长安建筑装饰系统设计

> 创建时间：2026-10-25

---

## 唐代建筑装饰元素

### 屋顶装饰
- **鸱吻**: 屋脊两端的装饰
- **脊兽**: 屋檐上的小动物
- **瓦当**: 屋檐前端的圆形装饰
- **滴水**: 屋檐下的三角形装饰

### 墙面装饰
- **壁画**: 宫殿寺庙墙上的画
- **匾额**: 门口的牌匾
- **楹联**: 门上的对联

### 门窗装饰
- **花窗**: 有花纹的窗户
- **格栅门**: 格子门
- **门钉**: 门上的铜钉
- **铺首**: 门上的兽头门环

---

## 不同建筑的装饰等级

| 建筑类型 | 装饰等级 |
|---|---|
| 皇宫 | 最高级（龙纹、金色） |
| 官署 | 中级（简化） |
| 寺庙 | 宗教装饰（佛像、莲花） |
| 贵族宅邸 | 较精美 |
| 平民住宅 | 简单朴素 |

---

## 程序化装饰生成
- 根据建筑类型自动添加对应装饰
- 不同坊区的装饰风格不同
- 节日时自动添加节日装饰（灯笼、春联）

---

*装饰是建筑的灵魂，让千篇一律的建筑有细节差异。*
