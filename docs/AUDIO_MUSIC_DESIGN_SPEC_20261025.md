# 音效与音乐设计规范（2026-10-25）

> 声音是沉浸感的另一半，需要空间音效、环境音、背景音乐三位一体。

---

## 一、环境音

### 按区域
| 区域 | 主要环境音 |
|---|---|
| 朱雀大街 | 行人脚步声、马车声、交谈声 |
| 西市 | 叫卖声、讨价还价、驼铃声、食物烹饪 |
| 东市 | 轻柔交谈、茶水声、字画展开、算盘声 |
| 普通坊 | 鸡鸣狗吠、邻里交谈、孩子嬉闹、井水声 |
| 慈恩寺 | 钟声、诵经声、木鱼声、风铃 |
| 曲江池 | 水波声、桨声、鸟鸣、远处钟声 |
| 大明宫 | 安静肃穆、脚步声、风吹铁马 |

### 按天气
- 晴天：轻微风声、鸟鸣
- 阴天：更安静、风声小
- 雨天：雨声、淅沥声
- 雪天：极安静、无声

---

## 二、音效

### 交互音效
- 脚步声：按地面材质（石板/土路/草地）
- 碰撞声：木箱/瓷器/金属
- 开门/关门声
- 拾取/丢弃声

### 活动音效
- 马蹄声
- 车轮声
- 叫卖声
- 打铁声
- 织布声

---

## 三、背景音乐

### 风格
- 唐代雅乐/清乐
- 古琴/琵琶/笛子
- 舒缓悠扬

### 按区域
| 区域 | 音乐风格 |
|---|---|
| 白天街市 | 轻快活泼 |
| 夜晚 | 舒缓宁静 |
| 宫苑 | 典雅庄重 |
| 寺庙 | 清净平和 |
| 曲江 | 诗意悠扬 |
