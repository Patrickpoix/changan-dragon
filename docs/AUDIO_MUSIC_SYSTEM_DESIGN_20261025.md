# 音效与音乐系统设计

> 设计文档版本：v1.0
> 日期：2026-10-25

---

## 一、背景音乐（BGM）

### 按区域分类
| 区域 | 音乐风格 |
|---|---|
| 宫城/官署 | 庄重雅乐 |
| 平民坊 | 安静，偶尔市井声 |
| 东市 | 热闹，丝竹 |
| 西市 | 胡乐，琵琶 |
| 寺庙 | 梵音，钟声 |
| 平康坊 | 流行，歌舞 |
| 曲江池 | 悠扬，古琴 |
| 朱雀大街 | 安静 |

### 昼夜差异
- 白天：轻柔背景音乐
- 夜晚：更安静，远处更鼓声

---

## 二、环境音效

### 按区域
| 区域 | 主要音效 |
|---|---|
| 大街 | 脚步声、马车声、人声 |
| 市集 | 叫卖声、讨价还价 |
| 河边 | 水声、船桨声 |
| 寺庙 | 钟声、诵经 |
| 居民区 | 鸡鸣狗吠 |

### 天气音效
- 雨：雨声渐强
- 风：风声呼啸
- 雪：安静

---

## 三、交互音效

### 动作音效
- 走路：脚步声
- 骑马：马蹄声
- 开门：吱呀声
- 灯笼点亮：噗的一声

### UI音效
- 按钮点击
- 对话框弹出
