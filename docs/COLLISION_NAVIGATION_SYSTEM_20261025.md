## 一、碰撞检测

### 静态碰撞
- 建筑碰撞盒（AABB）
- 地面碰撞（平面）
- 墙体碰撞

### 动态碰撞
- NPC之间（简单）
- 玩家与物体

### 技术方案
- Three.js内置Octree
- 或手动碰撞盒
- 不使用完整物理引擎（性能）

### 算法
- A*寻路
- 导航网格（NavMesh）
- 街道网络节点图

### NPC寻路
- 沿街道行走
- 避开其他NPC
- 到目的地停留
