# 长安项目：建筑Kit模块化设计

> 创建时间：2026-10-25

---

## 模块化理念

### 为什么模块化
- 108坊不可能逐个精模
- 用模块化组件拼装
- 不同组合产生不同建筑
- 程序化生成基础

## 拼装规则
- 根据坊类型选择不同组件
- 根据seed随机组合
- 保证每个建筑都不一样
- 但风格统一
