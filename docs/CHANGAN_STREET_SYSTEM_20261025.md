# 长安街道系统设计

> 创建时间：2026-10-25

---

## 街道等级

### 1. 朱雀大街（中轴线）
- **宽度**: 150米
- **长度**: 6.9公里
- **用途**: 皇帝出巡、大典
- **路面**: 石板路
- **行道树**: 槐树，整齐排列

### 2. 春明门/金光门大街（东西向主干道）
- **宽度**: 100米
- **长度**: 约9公里
- **用途**: 东西向交通要道
- **路面**: 石板路

### 3. 坊内十字街
- **宽度**: 15米
- **用途**: 坊内交通
- **路面**: 土路

### 4. 曲尺小巷
- **宽度**: 7米
- **用途**: 巷弄交通
- **路面**: 土路

## 街道设施

### 行道树
- **朱雀大街**: 国槐，两侧整齐排列
- **主干道**: 槐树/榆树
- **坊内**: 少量

### 路灯（灯笼杆）
- 每50m一个
- 朱红色灯笼
- 夜晚点亮

### 排水沟
- 街道两侧有排水沟
- 石板覆盖

## 街道人流密度

| 街道 | 白天密度 | 夜晚密度 |
|---|---|---|
| 朱雀大街 | 高 | 极低 |
| 东市门口 | 高 | 中（酒楼） |
| 西市门口 | 高 | 中 |
| 平康坊 | 中 | 高（夜晚） |
| 坊内街 | 中 | 低 |

---

## 街道宽度与比例
- 朱雀大街150m = 现代高速公路宽度
- 走在上面感觉非常宽阔
- 两侧建筑低矮，更显街道宏大

---

*街道是长安的骨架，150m宽的朱雀大街必须做出震撼感。*
