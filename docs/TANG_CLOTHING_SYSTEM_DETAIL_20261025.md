# 长安项目：唐代服饰制度

> 创建时间：2026-10-25

---

## 男子服饰

### 官员服饰
- **圆领袍**: 唐代男子常服
- **幞头**: 男子头巾
- **革带**: 腰带（带銙）
- **乌皮靴**: 靴子

### 品色制度
| 品级 | 颜色 |
|---|---|
| 三品以上 | 紫 |
| 四品 | 深绯 |
| 五品 | 浅绯 |
| 六品 | 深绿 |
| 七品 | 浅绿 |
| 八品 | 深青 |
| 九品 | 浅青 |

### 平民服饰
- **短褐**: 短打，劳动者穿
- **白衣**: 未做官的读书人

---

## 女子服饰

### 上衣
- **襦**: 短上衣
- **衫**: 单层上衣
- **袄**: 夹棉上衣

### 下裳
- **裙**: 裙子（齐胸襦裙最流行）
- **特点**: 高腰，显身材

### 配饰
- **披帛**: 肩上的长巾
- **高髻**: 各种高发髻
- **花钿**: 脸上的装饰
- **步摇**: 发饰

---

## 胡人服饰
- **翻领窄袖袍**: 西域风格
- **蹀躞带**: 挂东西的腰带
- **胡帽**: 西域帽子

---

*服饰是等级制度的体现，也是唐代审美的窗口。*
