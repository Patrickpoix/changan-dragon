# 长安UI与交互系统设计

> 创建时间：2026-10-25

---

## UI风格

### 唐代风格
- **字体**: 楷体/宋体
- **颜色**: 古风配色（朱红、金色、米黄）
- **装饰**: 唐代纹样（云纹、牡丹）

### 简洁原则
- 不遮挡太多画面
- 必要时才显示
- 沉浸式体验

---

## 主要UI

### HUD（游戏内）
- **小地图**: 右上角
- **任务提示**: 左上角
- **血量/体力**: 左下角
- **时辰/日期**: 右下角

### 菜单
- **背包**: Tab键打开
- **任务**: J键打开
- **地图**: M键打开
- **设置**: Esc键打开

### 交互提示
- **可交互物**: 靠近时显示提示
- **NPC对话**: 靠近时显示"按E对话"
- **拾取物品**: 地上有光效

---

## 操作方式

### 移动
- **WASD**: 移动
- **鼠标**: 视角
- **Shift**: 跑
- **空格**: 跳

### 交互
- **E**: 交互/对话
- **F**: 拾取
- **Tab**: 背包

---

*UI要简洁美观，不破坏沉浸感。*
