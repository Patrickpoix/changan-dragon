# Three.js开放世界游戏参考项目清单

> 文档版本：v1.0
> 日期：2026-10-25

## 一、开放世界探索类

### 1. grandma-gta（23星）
- 地址：https://github.com/andyhuo520/grandma-gta
- 描述：老奶奶GTA，浏览器可玩的台湾乡村开放世界，主角是72岁老奶奶
- 技术：Three.js，Tripo 3D
- 参考价值：浏览器开放世界的可行性

### 2. runguy（18星）
- 地址：https://github.com/abhiverse01/runguy
- 描述：小开放世界3D探索游戏，过河、爬山、收集宝珠
- 技术：Three.js + Vite
- 参考价值：第三人称控制、跳跃、冲刺

### 3. voxelcraft（15星）
- 地址：https://github.com/bridge-mind/voxelcraft
- 描述：单HTML文件的Minecraft风格体素游戏
- 技术：Three.js
- 参考价值：程序化世界生成

---

## 二、城市建造类

### 4. civitas（5星）
- 地址：https://github.com/reneodlt/civitas
- 描述：浏览器多人城市建造游戏，每个市民都模拟
- 技术：Three.js + TypeScript
- 参考价值：市民AI模拟

### 5. 都市·微城（2星）
- 地址：https://github.com/herozhong0125/city-builder
- 描述：Three.js 3D城市模拟建造：道路、分区、市政、交通、灾害、地标
- 技术：Three.js + Vite
- 参考价值：城市路网生成、建筑布局
