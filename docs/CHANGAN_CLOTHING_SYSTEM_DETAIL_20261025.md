# 长安服饰与穿着系统设计

> 创建时间：2026-10-25

---

## 唐代服饰制度

### 官员服饰（品色制度）
| 品级 | 颜色 |
|---|---|
| 三品以上 | 紫色 |
| 四品 | 深绯 |
| 五品 | 浅绯 |
| 六品 | 深绿 |
| 七品 | 浅绿 |
| 八品 | 深青 |
| 九品 | 浅青 |

### 男子服饰
- **圆领袍**: 唐代男子常服
- **幞头**: 男子头巾
- **革带**: 腰带
- **乌皮靴**: 靴子

### 女子服饰
- **齐胸襦裙**: 唐代女子标志性服装
- **披帛**: 肩上的长巾
- **高髻**: 各种高发髻
- **花钿**: 脸上的装饰

### 胡人服饰
- **翻领窄袖袍**: 西域风格
- **蹀躞带**: 挂东西的腰带
- **胡帽**: 西域帽子

---

## 玩家服饰系统
- **换装**: 可以更换服装
- **服饰收集**: 收集各种唐代服饰
- **声望解锁**: 高声望解锁高级服饰
- **节日服饰**: 节日限定服装

---

*服饰是唐代等级制度的体现，也是视觉丰富度的关键。*
