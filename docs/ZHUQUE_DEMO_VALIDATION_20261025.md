# 朱雀大街 Demo 技术验证（2026-10-25）

## 验证结论
✅ **Three.js r169 完全可行**，朱雀大街1km demo 已跑通

## 场景内容（等比例）
- 朱雀大街：150m宽 × 1000m长
- 坊墙两侧各一道，坊门每100m一个
- 城门楼（南端）、牌坊（中段）、9开间大殿（北端）
- 五重塔（东侧）、配殿（大殿两侧）、亭子（沿街点缀）
- 石狮一对、商铺两侧各10间
- 行道树40棵（InstancedMesh）
- NPC 4个骨骼动画行走 + 马车

## 技术指标
- gzip 后 JS 主包：**162 KB**
- 4K PBR 路面/墙面/树皮
- 4K HDRI 环境光
- ACES Filmic 色调映射
- PCFSoftShadowMap 2048阴影
- UnrealBloomPass 后处理
- 昼夜循环（20分钟一日）
- 雨粒子系统（3000粒子）
- 第三人称相机 + PointerLock

## 性能预期
- 桌面端：60fps（1km街道，11个GLB模型）
- DrawCall：~50（合批后）
- 可扩展到整个长安城（360个500m chunk）
