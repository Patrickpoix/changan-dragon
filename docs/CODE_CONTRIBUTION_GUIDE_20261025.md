# 代码贡献指南（2026-10-25）

> 如何为《龙游长安》贡献代码。

---

## 一、贡献方式

### 你可以贡献
- 新功能开发
- Bug修复
- 性能优化
- 文档完善
- 素材整理
- 测试验证

### 贡献原则
- 小步提交
- 清晰说明
- 测试验证
- 尊重社区

---

## 二、开始之前

### 找任务
- 看Issues列表
- 找good first issue
- 或自己提新想法

### 沟通
- 先讨论再开发
- 避免重复工作
- 对齐方向

---

## 三、开发流程

### 1. Fork仓库
- 先Fork到自己账号
- 克隆到本地

### 2. 创建分支
```bash
git checkout -b feature/your-feature-name
```

### 3. 开发代码
- 编写功能
- 测试验证
- 提交代码

### 4. 提交PR
- 推送到自己的fork
- 创建Pull Request
- 等待审查
- 响应反馈
- 合并到main

---

## 四、代码规范

### TypeScript
- 严格模式
- 类型完整
- 命名清晰

### Three.js
- 资源释放及时
- 性能意识
- 场景管理清晰

### 提交规范
- 格式：type: description
- 类型：feat/fix/docs/refactor/chore
- 示例：feat: add npc system

---

### 审查标准
- 功能正确
- 代码清晰

- 文档完整

### 审查流程
- 自动检查

- 修改完善
- 合并
