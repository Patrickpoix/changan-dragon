# 龙游长安 — 唐长安全比例开放世界

> 等比例复刻84平方公里唐长安城，用Three.js打造开放世界WebGL游戏。

---

## 项目愿景

参考《长安三万里》电影质感 + 《对马岛之魂》开放世界美术水准，
还原唐代长安108坊、朱雀大街、东西两市、大明宫、曲江池。
玩家化身小青龙，自由飞翔探索这座世界第一古都。

---

---

## 技术亮点

1. **流加载**: 500m chunk × 360块，3×3常驻 + 7×7预加载
2. **InstancedMesh**: 10万棵树 = 1个DrawCall
3. **LOD系统**: 4级距离层级，远距billboard
4. **程序化生成**: 108坊种子化随机，每坊特色不同
5. **昼夜天气**: 24h=20min，程序化天空着色器
