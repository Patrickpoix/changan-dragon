# 长安项目：开发工具与工作流

> 创建时间：2026-10-25

---

## 开发工具

### 编辑器
- **VS Code**: 代码编辑
- **Vite**: 开发服务器
- **Git**: 版本控制

### 3D工具
- **Blender**: 建模（可选）
- **ez-tree**: 程序化树木
- **TexturePacker**: 贴图打包

### 调试工具
- **Three.js Inspector**: 场景调试
- **Chrome DevTools**: 性能调试
- **Lighthouse**: 性能评分

---

## 开发工作流

### 日常开发
1. 修改代码
2. Vite热更新
3. 浏览器查看效果
4. 调试修改

### 素材生产
1. 搜索免费素材
2. 下载到本地
3. 处理压缩
4. 上传到仓库

### 数据生成
1. 修改坊配置
2. 运行生成器
3. 检查输出
4. 提交数据

---

## 版本管理
- **main分支**: 正式版
- **develop分支**: 开发版
- **feature分支**: 新功能
- **release分支**: 发布准备

---

*好的工具链和工作流是高效开发的基础。*
