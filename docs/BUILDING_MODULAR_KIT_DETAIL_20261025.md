## 为什么需要模块化
108坊不可能逐个手工建模。必须用模块化kit组合生成。

## 模块化组合规则

### 建筑生成算法
1. 根据坊区类型选择kit组合
2. 随机选择屋顶变体
3. 随机选择墙面材质
4. 随机插入门窗位置
5. 随机添加小品（灯笼、水缸）
6. 种子化随机（同一坊每次生成一样）

### 避免重复
- 每栋建筑有10%概率添加独特细节
- 颜色偏移±5%
- 尺寸缩放±10%
- 这样看起来每栋都不一样
