# 长安牌坊与建筑小品设计

> 创建时间：2026-10-25

---

## 建筑小品类型

### 1. 牌坊
- **用途**: 坊门口、重要建筑入口
- **形式**: 二柱一间、四柱三间
- **材质**: 木构或石构
- **颜色**: 朱红、彩绘
- **位置**: 各坊入口、大明宫前、曲江池畔

### 2. 石狮
- **用途**: 宫殿、寺庙、贵族宅邸门口
- **形式**: 一对（左雄右雌）
- **材质**: 青石
- **位置**: 明德门、大明宫、重要寺庙

### 3. 石灯笼
- **用途**: 寺庙庭院、陵墓
- **形式**: 多层石塔状
- **材质**: 花岗岩
- **位置**: 大慈恩寺、青龙寺、寺庙庭院

### 4. 石碑
- **用途**: 记事、功德、标识
- **形式**: 龟趺石碑
- **材质**: 青石
- **位置**: 国子监、寺庙、重要建筑前

### 5. 华表
- **用途**: 宫殿、陵墓前标识
- **形式**: 石柱，顶部有兽
- **材质**: 汉白玉
- **位置**: 大明宫前

### 6. 经幢
- **用途**: 寺庙内刻佛经
- **形式**: 石柱，多层
- **材质**: 青石
- **位置**: 寺庙庭院

---

## 小品分布

| 位置 | 小品类型 |
|---|---|
| 明德门 | 石狮一对 |
| 大明宫 | 华表、石狮 |
| 大慈恩寺 | 石灯笼、石碑 |
| 各坊入口 | 牌坊 |
| 曲江池 | 牌坊、石灯 |

---

*小品是城市细节的体现，让长安不只是空建筑。*
