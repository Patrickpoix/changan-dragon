# 操作控制方案

> 创建时间：2026-10-25

---

## 键盘控制（PC端）

### 移动
| 按键 | 功能 |
|---|---|
| W | 前进 |
| S | 后退 |
| A | 左移 |
| D | 右移 |
| Shift | 加速跑/飞 |
| 空格 | 跳跃/起飞 |

### 视角
| 按键 | 功能 |
|---|---|
| 鼠标移动 | 转视角 |
| 鼠标滚轮 | 缩放距离 |
| 右键按住 | 锁定视角 |

### 互动
| 按键 | 功能 |
|---|---|
| E | 互动/对话/拾取 |
| R | 变身（龙/人） |
| F | 飞行模式开关 |
| M | 打开大地图 |
| Tab | 打开任务/背包 |
| Esc | 菜单 |

---

## 移动端控制

### 虚拟摇杆
- 左下角：移动摇杆
- 右下角：视角滑动区

### 按钮
- 右下角大按钮：跳跃/起飞
- 右上角小按钮：互动
- 右上角菜单按钮

---

## 相机模式

### 第三人称跟随（默认）
- 相机在玩家身后3米
- 高度2米
- 平滑跟随
- 可调节距离（滚轮）

### 第一人称
- 相机在玩家眼睛位置
- 沉浸式体验
- 适合进建筑内

### 自由飞行视角
- 飞行时相机拉高
- 可俯瞰全城
- 速度更快

---

## 自动功能
- 自动寻路：点击地图位置自动走过去
- 自动奔跑：长按Shift切换
- 自动拾取：走近自动捡东西

---

*操作要简单直觉，不要复杂按键组合。*
