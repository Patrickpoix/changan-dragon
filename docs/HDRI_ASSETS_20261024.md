## 意义

至此已覆盖一天三个核心时段的环境光：
- 清晨：柔和暖金，晨雾感

- 黄昏：夕阳暖调，电影感

配合项目已有美术方向（朱红木构 + 灰青瓦 + 暖石台基），可实现《长安三万里》式的暖金夕照 + 《大理寺日志》式的干净明快双风格。
