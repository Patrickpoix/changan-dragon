## 1. 核心算法

### 1.1 种子化随机
```javascript
function mulberry32(seed) {
  return function() {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  }
}
```
- 每个坊有固定 seed，保证布局可复现
- seed = hash(坊名)，同名坊永远生成相同布局

### 1.2 布局生成流程
```
1. 读取坊的 bbox（考古坐标）
2. 根据功能分区类型选择建筑模板权重
3. 在坊内网格上随机放置建筑（带间距约束）
4. 沿坊内街道两侧放置行道树
5. 坊门位置对齐考古坐标
6. 特殊建筑（寺庙/市场/大宅）放置在坊内核心位置
7. 生成 NPC 点位（按功能分区分配数量和类型）
8. 导出 JSON
```
