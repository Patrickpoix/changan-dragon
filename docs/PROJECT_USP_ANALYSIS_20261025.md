# 项目独特卖点（USP）分析

> 设计文档版本：v1.0
> 日期：2026-10-25

---

## 一、我们的独特之处

### 1. 全比例84km²长安
- 不是小场景demo
- 是完整的开放世界
- 108坊等比例复刻

### 2. 千坊千面
- 不是批量生成同质化
- 每个坊有不同功能
- 建筑风格、人物、业态都不同

### 3. 电影级美术
- 国风漫剧/电影质感
- 参考《长安三万里》
- 参考《对马岛之魂》

### 4. 浏览器免费游玩
- 不需要下载安装
- 打开网页就能玩
- 免费CC0素材

## 二、目标用户
- 唐代文化爱好者
- 国风游戏玩家
- 历史教育用途
- 开放世界探索爱好者
