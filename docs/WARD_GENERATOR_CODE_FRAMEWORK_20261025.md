## 二、单坊生成流程

### 输入参数
```javascript
{
  // 位置
  x: 坊X坐标,
  z: 坊Z坐标,
  
  // 功能类型
  type: 'noble' | 'official' | 'east_market' | 'west_market' | 'common' | 'temple' | 'entertainment',
  
  // 随机种子
  seed: 12345,
  
  // 尺寸
  width: 500,  // 坊宽（米）
  depth: 500,   // 坊深（米）
}
```

### 生成步骤
1. **生成坊墙**
   - 四面围墙
   - 四个方向坊门
   - 围墙高度按类型调整

2. **划分内部街道**
   - 十字街或井字街
   - 街道宽度按类型调整

3. **分配地块**
   - 沿街商铺
   - 内部宅院
   - 寺庙/公共空间

4. **生成建筑**
   - 按类型选建筑kit
   - 随机旋转、缩放
   - 固定seed保证一致性

5. **点缀细节**
   - 树木
   - NPC
   - 灯笼/招牌

## 四、随机化策略

### mulberry32种子化随机
```javascript
function mulberry32(seed) {
  return function() {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  }
}
```

### 为什么用固定seed
- 每次生成结果一致
- 不会重进游戏就变样
- 可以微调单个坊
