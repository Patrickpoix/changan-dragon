# 渲染管线技术实现（2026-10-25）

> 电影级画质的渲染管线方案。

---

## 一、渲染设置

### 渲染器
- WebGLRenderer
- ACES Filmic色调映射
- PCFSoftShadowMap 4096

### 输出
- sRGB输出
- 抗锯齿（FXAA）

## 二、光照系统

### 主光
- **方向光**（太阳）
- 颜色随时间变化
- 强度随时间变化
- 阴影：PCFSoft 4096

### 环境光
- **半球光**：天空蓝+地面土色
- **HDRI**：环境反射

### 点光源
- 灯笼：自发光
- 窗户灯光
- 火把/篝火

## 三、材质系统

### PBR材质
- 金属度/粗糙度工作流
- baseColor + normal + roughness + metalness
- 4K分辨率

### 材质类型
| 类型 | 特征 |
|---|---|
| 瓦/屋面 | 灰青色，粗糙，有瓦垄 |
| 木/漆木 | 暖褐/赭红，木纹 |
| 灰泥/夯土 | 土白/米灰，粗糙 |
| 石/砖 | 温灰，有纹理 |
| 布/丝绢 | 织物纹理，半透明 |
| 陶/瓷 | 釉面光滑 |
| 皮肤 | 温润，次表面散射 |

## 六、性能优化

### 渲染优化
- InstancedMesh合批
- LOD分级
- 距离裁剪
- 纹理压缩（KTX2）

### 画质开关
- 高/中/低三档
- 高：4K纹理+4096阴影+后处理全开
- 中：2K纹理+2048阴影+部分后处理
- 低：1K纹理+1024阴影+无后处理
