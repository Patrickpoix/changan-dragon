# 长安项目：108坊差异化策略详细

> 创建时间：2026-10-25

---

## 问题
- 不能千坊一面
- 每个坊要有自己的特色
- 不能批量生成同质化严重

---

## 差异化策略

### 1. 功能差异化
每坊有不同功能：
- **官署坊**: 官署建筑，官员NPC多
- **贵族坊**: 大宅邸，围墙高
- **平民坊**: 小民居，热闹
- **寺庙坊**: 寺庙为主，香客多
- **商业坊**: 商铺密集，商人多
- **娱乐坊**: 青楼酒楼，夜晚热闹

### 2. 建筑风格差异化
| 坊类型 | 屋顶 | 墙面 | 高度 |
|---|---|---|---|
| 官署坊 | 灰瓦 | 朱红 | 2层 |
| 贵族坊 | 灰瓦 | 白墙 | 2层 |
| 平民坊 | 灰瓦 | 土墙 | 1层 |
| 寺庙坊 | 琉璃瓦 | 黄墙 | 多层 |
| 商业坊 | 灰瓦 | 木板 | 2层 |

### 3. NPC差异化
| 坊类型 | 主要NPC |
|---|---|
| 官署坊 | 官员、士兵 |
| 贵族坊 | 家仆、侍女 |
| 平民坊 | 百姓、小贩 |
| 寺庙坊 | 和尚、香客 |
| 商业坊 | 商人、顾客 |
| 娱乐坊 | 歌女、食客 |

### 4. 植被差异化
| 坊类型 | 植被 |
|---|---|
| 贵族坊 | 牡丹、竹子 |
| 寺庙坊 | 古松、银杏 |
| 平民坊 | 枣树、柳树 |
| 园林坊 | 垂柳、荷花 |

---

## 种子化随机
- 每坊固定seed
- 根据seed随机组合组件
- 保证每坊都不一样
- 但风格统一

---

## 手动精修
- 14个A级地标手工精修
- 重要坊（平康、西市、东市）精修
- 其他坊程序化生成
