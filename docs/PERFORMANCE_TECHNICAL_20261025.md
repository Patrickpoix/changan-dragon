## 1. 优化成果

| 优化技术 | 效果 |
|---|---|
| InstancedMesh 合批 | DrawCall 从 4,383 → 17（258x） |
| 三级 LOD | 远距离 billboard/fog |

| 程序化天空 | 零 HDRI 依赖 |
