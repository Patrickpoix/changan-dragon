# 长安项目：唐代108坊功能清单

> 创建时间：2026-10-25

---

## 108坊功能分类

### 宫城附近（北部）
- **宫城**: 皇宫
- **皇城**: 百官衙署
- **特点**: 政治中心

### 贵族住宅区（东部）
- **特点**: 达官贵人住
- **坊**: 兴宁坊、道政坊等
- **建筑**: 大宅邸

### 寺庙区
- **大慈恩寺**: 晋昌坊（大雁塔）
- **荐福寺**: 开化坊（小雁塔）
- **大兴善寺**: 靖善坊
- **青龙寺**: 新昌坊

### 商业区
- **东市**: 城东南（高档）
- **西市**: 城西南（国际贸易）

### 娱乐区
- **平康坊**: 城东北（青楼）
- **特点**: 歌女聚集地

### 园林区
- **曲江池**: 城东南
- **特点**: 皇家园林

### 平民区
- **西部南部**: 普通百姓
- **特点**: 小民居

### 文化区
- **国子监**: 务本坊
- **特点**: 最高学府

## 108坊特点
- **坊坊不同**: 每个坊功能不同
- **建筑不同**: 建筑风格随功能变
- **人不同**: 住的人不同
- **商业不同**: 业态不同

## 玩家体验
- **逛不同的坊**: 每个坊有不同感觉
- **东市 vs 西市**: 两个市完全不同
- **平康坊**: 娱乐区
- **曲江池**: 风景区
