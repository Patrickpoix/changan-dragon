# 长安娱乐与休闲系统设计

> 创建时间：2026-10-25

---

## 唐代娱乐活动

### 文人娱乐
- **吟诗**: 作诗、对诗
- **作画**: 绘画、书法
- **下棋**: 围棋、象棋
- **品茶**: 茶艺、茶会

### 市井娱乐
- **看戏**: 戏台表演
- **听说书**: 说书人讲古
- **斗鸡**: 斗鸡赌博
- **斗蟋蟀**: 秋季活动

### 体育活动
- **马球**: 唐代最流行的运动
- **射箭**: 骑马射箭
- **蹴鞠**: 古代足球

### 节庆娱乐
- **赏灯**: 上元节赏灯
- **赛龙舟**: 端午节
- **赏月**: 中秋节
- **登高**: 重阳节
