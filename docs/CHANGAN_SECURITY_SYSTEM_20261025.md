# 长安治安系统设计

> 创建时间：2026-10-25

---

## 唐代治安体系

### 金吾卫
- 负责长安城治安
- 巡逻街道
- 管理城门

### 坊正
- 每坊设坊正
- 管理坊内事务
- 维护坊内秩序

### 武侯铺
- 街头派出所
- 分布在各城门和重要路口
- 处理案件

---

## 宵禁制度

### 宵禁时间
- 日落时分（约19:00）开始
- 日出时分（约5:00）解除

### 宵禁内容
- 街上不能随意行走
- 有事要请假条
- 违反要被抓

### 例外
- 上元灯节（正月十五）解除宵禁
- 官员急事可以通行

---

## 玩家治安系统
- **宵禁提醒**: 晚上提醒玩家回坊
- **被抓惩罚**: 宵禁在街上会被抓
- **罚款/拘留**: 违反治安的惩罚
- **声望系统**: 做好事提升声望

---

*宵禁是唐代城市管理的重要特色，要体现出来。*
