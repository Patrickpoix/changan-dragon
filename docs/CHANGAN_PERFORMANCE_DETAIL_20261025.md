## 优化策略

### 渲染优化
1. **InstancedMesh**: 相同模型合批（树木=1 DrawCall）
2. **LOD系统**: 4级距离层级
3. **Frustum Culling**: 视锥剔除
4. **遮挡剔除**: 遮挡物剔除

### 内存优化
1. **DRACO压缩**: 几何压缩80%
2. **KTX2压缩**: 纹理压缩75%
3. **LRU缓存**: chunk卸载
4. **共享材质**: 相同材质复用

### 加载优化
1. **流式加载**: 500m chunk
2. **预加载**: 7×7 chunk预加载
3. **双缓冲**: 预加载和卸载并行
4. **优先级**: 近处先加载
