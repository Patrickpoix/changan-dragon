# 唐代建筑形制规范

> 设计文档版本：v1.0
> 日期：2026-10-25
> 依据：南禅寺大殿、佛光寺东大殿等唐代木构实例

---

## 一、唐代建筑总体特征

与宋代建筑相比，唐代建筑有以下特点：

| 维度 | 唐代 | 宋代 | 差异要点 |
|---|---|---|---|
| 斗拱 | 硕大，占柱高1/2 | 变小，装饰化 | 唐代斗拱是结构核心 |
| 出檐 | 深远（可达4米） | 较浅 | 唐代出檐更深远 |
| 屋顶坡度 | 平缓（1:2） | 较陡（1:3） | 唐代屋顶更平缓 |
| 鸱吻 | 鸱尾形状 | 鸱吻 | 唐代尾部分叉 |
| 木构色彩 | 朴素（赭、红） | 华丽 | 唐代少装饰 |
| 台基 | 高大须弥座 | 较低 | 唐代台基更雄伟 |
| 柱子 | 粗壮，有收分 | 较细 | 唐代柱子更粗壮 |

## 二、单体建筑形制

### 1. 殿堂型建筑（宫殿/寺庙主殿）

**面阔间数**：
- 最高等级：11间（如大明宫含元殿）
- 大寺：9间
- 王府：7间
- 普通官署：5间

**面阔尺寸**：
- 每间约5-6m
- 9间大殿：面阔约45-54m

**进深**：
- 4-6椽架
- 约10-15m

**柱高**：
- 约5-7m
- 柱径约0.5-0.7m

**屋顶形式**：
- 最高等级：重檐庑殿顶
- 次等级：重檐歇山顶
- 一般：单檐庑殿/歇山

### 2. 楼阁型建筑（塔楼/钟楼）

**层数**：
- 2-3层为主
- 佛塔可达5-7层

**特点**：
- 每层有平座回廊
- 逐层收分
- 每层出檐

### 3. 亭榭型建筑

**形制**：
- 四角攒尖、六角攒尖、八角攒尖
- 面宽3-5m
- 高度4-6m

### 4. 民居建筑

**形制**：
- 悬山顶或硬山顶
- 面阔3-5间
- 单层为主
- 朴素无装饰

## 三、斗拱系统（唐代核心特征）

### 斗拱组成
- **斗**：斗形木块
- **拱**：弓形横木
- **昂**：斜向构件
- **翘**：向上翘起的拱

### 唐代斗拱特点
1. 体量硕大（占柱高1/3-1/2）
2. 结构作用强（支撑深远出檐）
3. 出跳多（3-5跳）
4. 装饰少（简洁有力）

### 等级差异
- 最高等级：双抄双下昂（4跳）
- 大寺：双抄单下昂（3跳）
- 普通：单抄单昂（2跳）
- 民居：无斗拱（简单挑檐）

---

## 四、屋顶形制

### 屋顶等级（从高到低）
1. **重檐庑殿顶** - 最高级（皇宫主殿、大寺主殿）
2. **重檐歇山顶** - 次高级（宫门、城门楼）
3. **单檐庑殿顶** - 高级（佛殿）
4. **单檐歇山顶** - 中级（官署、配殿）
5. **悬山顶** - 普通（民居、商铺）
6. **硬山顶** - 最低（平民住宅）
7. **攒尖顶** - 亭、塔

### 屋顶坡度
- 唐代：约1:2（高:水平距离）
- 屋面曲线：凹曲线（两头翘，中间平缓）

### 脊饰
- **正脊两端**：鸱尾（唐代特有，尾部分叉向上）
- **垂脊**：脊兽（唐代数量少）
- **檐角**：套兽

## 五、色彩与材质

### 唐代建筑色彩
| 部位 | 颜色 | 说明 |
|---|---|---|
| 木柱 | 赭红色 | 最常用 |
| 门窗 | 赭红/深棕 |
| 墙面 | 白色（粉墙） | 官式建筑 |
| 墙面 | 夯土黄色 | 平民住宅 |
| 屋顶瓦 | 深灰/黑 | 最普遍 |
| 屋顶瓦 | 绿色琉璃 | 寺庙/宫殿 |
| 台基 | 青石/汉白玉 | 高级建筑 |

### 唐代 vs 宋代色彩差异
- 唐代：更朴素，少彩绘
- 宋代：更华丽，有彩画
- 我们项目：偏唐代风格，少装饰

---

## 六、台基与台阶

### 台基等级
1. **须弥座** - 最高等级（宫殿、大寺）
   - 多层线脚
   - 雕刻装饰
   - 高度1-2m

2. **石台基** - 中等（官署、贵族宅）
   - 条石砌筑
   - 高度0.5-1m

3. **土台基** - 普通（平民）
   - 夯土
   - 高度0.2-0.3m

### 台阶
- **踏跺**：多级石阶
- **垂带石**：两侧斜石
- **御路**：中间云龙浮雕（最高等级）

## 七、对我们程序化生成的指导

### 参数化设计
每个建筑生成器应包含以下参数：
```javascript
{
  // 等级决定形制
  rank: 'imperial' | 'noble' | 'official' | 'common' | 'humble',
  
  // 面阔间数
  bays: 5 | 7 | 9 | 11,
  
  // 屋顶形式
  roofType: 'wudian' | 'xieshan' | 'xuanshan' | 'yingshan' | 'cuanjian',
  
  // 层数
  stories: 1 | 2 | 3,
  
  // 是否重檐
  doubleEave: true | false,
  
  // 斗拱出跳数
  dougongTiao: 2 | 3 | 4,
  
  // 台基高度
  platformHeight: 0.3 | 0.6 | 1.2,
  
  // 色彩模式
  colorScheme: 'tang_plain' | 'song_decorated' | 'monastery_red'
}
```
