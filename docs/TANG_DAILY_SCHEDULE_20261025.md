## 唐代计时

### 时辰
- **一天12个时辰**
- **每个时辰=2小时**

### 12时辰
| 时辰 | 现代时间 | 活动 |
|---|---|---|
| 子时 | 23-1点 | 睡觉 |
| 丑时 | 1-3点 | 睡觉 |
| 寅时 | 3-5点 | 睡觉 |
| 卯时 | 5-7点 | 起床、开市 |
| 辰时 | 7-9点 | 早朝、工作 |
| 巳时 | 9-11点 | 工作 |
| 午时 | 11-13点 | 吃饭休息 |
| 未时 | 13-15点 | 工作 |
| 申时 | 15-17点 | 工作 |
| 酉时 | 17-19点 | 收市、下班 |
| 戌时 | 19-21点 | 夜晚活动 |
| 亥时 | 21-23点 | 睡觉 |

---

## 一日作息

### 早上（卯时）
- **起床**: 日出而作
- **开市**: 商店开门
- **早朝**: 官员上朝

### 白天（辰时-申时）
- **工作**: 上班工作
- **市场**: 市场热闹
- **活动**: 各种活动

### 傍晚（酉时）
- **收市**: 商店关门
- **下班**: 官员下班
- **坊门**: 坊门关闭

### 夜晚（戌时-亥时）
- **宵禁**: 街上不能走
- **在家**: 在家休息
- **平康坊**: 最热闹

---

## 更夫
- **打更**: 晚上打更报时
- **巡逻**: 巡逻街道
- **特点**: 宵禁的执行者

---

## 玩家时间系统
- **时辰显示**: HUD显示当前时辰
- **作息**: NPC按时辰活动
- **宵禁**: 晚上不能在街上走
- **打更声**: 晚上听到打更声
