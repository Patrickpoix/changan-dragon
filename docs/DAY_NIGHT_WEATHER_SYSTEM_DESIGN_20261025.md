## 一、昼夜循环系统

### 时间比例
- 游戏内24小时 = 现实20分钟
- 每小时游戏时间 = 50秒现实时间

### 时段划分
| 时段 | 游戏时间 | 现实时长 | 特征 |
|---|---|---|---|
| 黎明 | 5:00-7:00 | ~1分40秒 | 天色渐亮，薄雾 |
| 上午 | 7:00-11:00 | ~3分20秒 | 阳光明亮 |
| 正午 | 11:00-13:00 | ~1分40秒 | 顶光，阴影短 |
| 下午 | 13:00-17:00 | ~3分20秒 | 斜射光 |
| 黄昏 | 17:00-19:00 | ~1分40秒 | 金色夕阳，最美 |
| 入夜 | 19:00-21:00 | ~1分40秒 | 灯笼点亮 |
| 深夜 | 21:00-5:00 | ~6分40秒 | 星空，安静 |

### 光照变化
- **太阳角度**：程序化计算
- **太阳颜色**：
  - 正午：白色偏暖
  - 黄昏：橙红色
  - 清晨：淡金色
- **阴影**：PCFSoftShadowMap
- **环境光**：随时间变化强度和颜色

## 二、天空系统

### 程序化天空Shader
- 天空颜色渐变（地平线→天顶）
- 太阳位置和光晕
- 月亮和星星（夜晚）
- 云层（可选）

### 关键参数
| 时段 | 天顶色 | 地平线色 | 太阳亮度 |
|---|---|---|---|
| 正午 | #4a9eff | #b8d8ff | 1.0 |
| 黄昏 | #2a4a8a | #ff8a4a | 0.6 |
| 夜晚 | #0a0a2a | #1a1a3a | 0.0（月亮） |
| 黎明 | #4a6aaa | #ffaa8a | 0.3 |

## 三、天气系统

### 天气类型
1. **晴天** - 默认，最多
2. **多云** - 云层遮挡阳光
3. **阴天** - 灰蒙蒙
4. **小雨** - 细雨绵绵
5. **大雨** - 倾盆大雨
6. **雪天** - 冬季特有
7. **雾天** - 晨雾

### 天气概率
- 春季：晴40%，多云30%，雨20%，雾10%
- 夏季：晴30%，多云20%，雷阵雨30%，雾20%
- 秋季：晴50%，多云30%，雨10%，雾10%
- 冬季：晴40%，多云30%，雪20%，阴10%

### 天气效果
| 天气 | 视觉效果 | 音效 |
|---|---|---|
| 晴天 | 正常光照 | 鸟鸣、风声 |
| 多云 | 光照减弱 | 风声 |
| 阴天 | 灰蒙，阴影淡 | 沉闷 |
| 小雨 | 雨丝粒子，地面湿 | 雨声 |
| 大雨 | 密集雨，水花 | 大雨声 |
| 雪天 | 雪花飘落 | 安静 |
| 雾天 | 指数雾增强 | 安静 |

## 四、夜晚灯光系统

### 灯笼
- 沿街灯笼：每50m一个
- 商铺灯笼：门口悬挂
- 寺庙灯笼：殿前
- 效果：PointLight + Bloom

### 夜晚氛围
- 灯笼Bloom强度：0.8
- 整体环境光：很低
- 月光：冷蓝色
- 上元灯节：Bloom强度2.0 + 1万孔明灯

### 节日特殊效果
- **上元节（元宵）**：全城灯笼，孔明灯升空
- **中秋节**：满月，赏月
- **春节**：鞭炮（可选）

## 五、后处理效果

### 必须的后处理
1. **Bloom** - 发光效果（灯笼、太阳）
2. **FXAA** - 抗锯齿
3. **Vignette** - 暗角（电影感）
4. **Color Grading** - 颜色分级

### 电影感调色
- 整体偏暖色调
- 阴影偏蓝紫
- 高光偏暖黄
