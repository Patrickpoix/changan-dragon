# 植被系统 — 技术实现文档

> 版本：v1.0
> 状态：✅ 程序化生成方案确定

---

## 1. 技术方案

基于 ez-tree 程序化树木生成方案。

### 1.1 核心特性
- 程序化生成树木（无外部GLB）
- LOD 分级（近精模/远billboard）
- 风动动画（shader）
- 季节变化（春樱/夏绿/秋黄/冬雪）

---

## 2. 树种规划

| 树种 | 应用场景 | 数量 |
|---|---|---|
| 松树 | 寺庙/陵墓/行道 | 大量 |
| 柳树 | 曲江池/河边 | 中量 |
| 樱花树 | 曲江池/园林 | 少量 |
| 梧桐 | 街道 | 中量 |
| 牡丹 | 园林/贵族宅 | 少量 |
| 竹子 | 寺庙/园林 | 少量 |

---

## 3. 性能数据

| 指标 | 数值 |
|---|---|
| 总树木数 | 109,784 |
| 合批方式 | InstancedMesh |
| DrawCall | 1（全树种） |
| 风动 | GPU shader |

---

## 4. 布局规则
- 朱雀大街两侧：松树（间距20m）
- 坊内街道：梧桐/槐树
- 曲江池边：柳树
- 寺庙内：松树
- 贵族宅：牡丹/竹子
- 平民坊：少树
