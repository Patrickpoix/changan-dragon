## 一、重要节日

### 上元节（正月十五）
- 取消宵禁三天
- 满城灯火
- 赏灯、猜谜、约会
- 最热闹的节日

### 上巳节（三月三）
- 曲江池踏青
- 赏花饮酒
- 新进士游宴

### 端午节（五月五）
- 吃粽子
- 赛龙舟（曲江池）

### 中秋节（八月十五）
- 赏月
- 吃月饼
- 团圆

### 重阳节（九月九）
- 登高
- 插茱萸
