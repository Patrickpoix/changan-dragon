# 大型建筑与角色动物素材深度研究（2026-10-24）

## 一、动物素材（已确认可用）

### Quaternius Animated Animal Pack ★★★★★
- 来源: https://poly.pizza/bundle/Animated-Animal-Pack-ILAPXeUYiS
- 许可: CC0 1.0（完全免费，可商用）
- 格式: GLTF / FBX / OBJ / Blend
- 内容: 12 种动物，每种 12+ 动画（走、跑、跳、攻击、死亡等）
- 包含: 马、驴、牛、羊、猪、狗、青蛙、鹿等
- 用途: 长安街市场景、丝绸之路商队、运输马队
- 评价: 低多边形风格，但有完整动画，适合大场景人群/动物密度

## 二、大型建筑程序化生成方案（核心突破）

### 1. YingzaoLab 营造法式数驱参构系统 ★★★★★
- 来源: https://coding-x.tech/docs/yingzaolab/
- 许可: 开源项目（需确认具体协议）
- 内容: 基于《营造法式》的参数化建筑生成系统
- 核心模块: DouGong（斗拱）、PuZuo（铺作）的 JSON 参数模板
- 意义: 可以程序化生成符合宋代/唐代形制的木构建筑
- 适用性: 可作为项目建筑生成器的设计参考，或直接移植参数逻辑

### 2. Medieval Chinese Timber Buildings Procedural Generator
- 来源: https://zenodo.org/records/7837875
- 许可: 开源（Zenodo 通用许可）
- 内容: Blender Python 脚本 + 生成的 3D 模型
- 功能: 参数化生成中世纪中式木构建筑的结构系统
- 作者: 学术研究项目
- 意义: 有完整的建筑结构生成算法，可直接参考

### 3. 斗拱参数化研究
- 多篇学术论文研究了斗拱的参数化建模和生成规则
- 《营造法式》的"材份制"是完美的模块化设计系统
