# 长安NPC行为树系统设计

> 创建时间：2026-10-25

---

## 行为树架构

### 基础节点类型
- **Selector（选择节点）**: 按优先级尝试子节点
- **Sequence（顺序节点）**: 按顺序执行子节点
- **Parallel（并行节点）**: 同时执行多个子节点
- **Action（动作节点）**: 执行具体行为
- **Condition（条件节点）**: 判断条件

---

## 典型NPC行为树

### 平民百姓
```
Selector
├── 吃饭时间？
│   └── 回家吃饭
├── 工作时间？
│   └── 去工作地点
├── 晚上？
│   └── 回家休息
└── 白天？
    └── 在坊内活动
        ├── 去市场购物
        ├── 在井边打水
        └── 在门口闲聊
```

### 商人（西市胡商）
```
Selector
├── 早上开门
│   └── 去店铺开门
├── 营业时间
│   └── 在店铺招呼客人
│       ├── 有客人？交易
│       ├── 没客人？整理货物
│       └── 补货？去仓库
└── 晚上关门
    └── 回家
```

### 官员
```
Selector
├── 早朝时间？
│   └── 去皇宫上朝
├── 办公时间？
│   └── 去官署办公
└── 下班后
    ├── 去酒楼应酬
    └── 回家
```
