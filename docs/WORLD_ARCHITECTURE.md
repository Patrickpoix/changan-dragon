# 龙游长安 · 完整长安城世界架构设计

## 1. 历史基准

唐长安城（隋大兴城）实测规模：
- 外郭城东西约9720m，南北约8650m（含城墙）
- 宫城在北中，皇城在宫城南，朱雀大街为南北中轴
- 108坊 + 东市（都会市）+ 西市（利人市）
- 明德门为正南门，五个门道
- 大明宫在东北龙首原，兴庆宫在东城，曲江池在东南

## 2. 坐标映射方案

### 当前原型
- 游戏坐标: x∈[-450,450], z∈[-380,380]（900×760单位）
- 1单位 ≈ 2m → 实际1.8×1.52km
- 这只是朱雀大街-明德门核心段的原型

- 游戏坐标: x∈[-2400,2400], z∈[-2100,2100]（4800×4200单位）

- 宫城/玄武门: z=-2100（最北）

## 3. 坊市网格

- 东西14列坊，南北13行坊（除去宫城/皇城/两市占用地块）
- 每坊约160×150单位 ≈ 320×300m
- 街道宽：朱雀大街26单位(52m)，其他大街15单位(30m)，坊间小街8单位(16m)
- 东市/西市各占两坊之地

## 4. 分区流式加载架构

### 4.1 分区方案
将长安城分为3×3=9个大区，每区1600×1400单位：

| | 西(x负) | 中(x=0) | 东(x正) |
|---|---------|---------|--------|
| 北(z负) | 西北坊+西内苑 | 宫城+皇城 | 东北+大明宫 |
| 中(z=0) | 西市+西坊 | 朱雀大街+皇城前 | 东市+东坊+兴庆宫 |
| 南(z正) | 西南坊+小雁塔 | 明德门+南郊 | 东南+大雁塔+曲江池 |

### 4.2 加载距离
- 玩家周围1个大区(3200×2800单位)内：高细节，全建筑+NPC+植被
- 周围2个大区(4800×4200)：中细节，建筑简化，无NPC
- 3个大区以外：低细节，仅远景天际线

### 4.3 资源生命周期
- 进入新大区：异步加载该区建筑/植被/水面，1-2秒淡入
- 离开大区：保留缓存5分钟后卸载纹理和几何体
- 首屏只加载当前所在区(朱雀大街-明德门)，其余后台预加载相邻区

## 5. LOD策略

| 距离 | 精度 |
|------|------|
| <100m | 高模+PBR贴图+细节装饰 |
| 100-300m | 中模，简化屋顶和斗拱 |
| 300-800m | 低模，方块化建筑 |
| >800m | 天际线盒体+雾效遮挡 |

## 6. 架空奇观布局原则

历史复原区（严格按历史）：
- 宫城、皇城、城墙、城门、街道骨架、大雁塔、小雁塔、曲江池

架空奇观区（艺术创作）：
- 大明宫上空：云中楼阁、悬空栈道、飞阁流丹
- 曲江池上方：彩虹桥、月宫倒影、莲花浮空岛
- 城市边缘：巨大灯柱、灯笼浮空岛、星空瀑布
- 架空元素不影响历史建筑的可通行区域

## 8. 世界数据格式

所有城市布局存储在JSON中，不硬编码在JS里：
```js
// world/changan-layout.json
{
  "scale": { "unit": 2, "description": "1 unit = 2 meters" },
  "walls": { "x0": -2400, "x1": 2400, "z0": -2100, "z1": 2100 },
  "gates": [...],
  "wards": [...],
  "landmarks": [...],
  "roads": [...],
  "fantasy": [...]
}
```

程序化生成器读取此JSON批量生成坊墙、建筑和植被，生成结果审核后固定。
