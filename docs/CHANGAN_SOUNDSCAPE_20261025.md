# 长安声音景观设计

> 创建时间：2026-10-25

---

## 声音是沉浸感的另一半

### 不同区域的声音

#### 朱雀大街
- 脚步声（石板路）
- 马车声
- 远处叫卖声
- 鸟鸣

#### 西市
- 多语言叫卖声
- 讨价还价声
- 骆驼叫声
- 人群喧闹
- 各种店铺音乐

#### 东市
- 相对安静
- 酒楼音乐声
- 文人谈笑声

#### 寺庙
- 钟声（早晚）
- 诵经声
- 木鱼声
- 寂静

#### 平民坊
- 市井喧哗
- 孩童玩耍
- 鸡鸣狗吠
- 做饭声

#### 曲江池
- 水声
- 鸟鸣
- 吟诗声
- 微风声

---

## 时辰声音变化

| 时间 | 主要声音 |
|---|---|
| 清晨 | 钟声、早起开门声 |
| 上午 | 市集喧闹、叫卖 |
| 中午 | 午饭、休息 |
| 下午 | 继续市集、逛街 |
| 傍晚 | 回家、晚饭 |
| 夜晚 | 打更声、虫鸣、安静 |

---

## 天气声音
- **晴天**: 鸟鸣、风声
- **雨天**: 雨声、远处雷声
- **雪天**: 非常安静
- **大风**: 风声、树叶沙沙

---

## 技术实现
- 3D PositionalAudio
- 声音随距离衰减
- 近大远小
- 环境音叠加
- BGM按时辰切换
