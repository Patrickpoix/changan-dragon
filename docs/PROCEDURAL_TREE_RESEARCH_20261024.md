# 程序化树木生成方案研究（2026-10-24）

> 针对唐长安园林垂柳、松树、花树等动态树木需求，调研可直接复用的 Three.js 程序化树木生成方案。

## 二、ez-tree 详解（推荐方案）

### 基本信息
- 仓库：https://github.com/dgreenheck/ez-tree
- Stars：1717
- 在线演示：https://eztree.dev
- 安装：`npm i @dgreenheck/ez-tree`

### 核心特性
1. **数十个可调参数**：树干、树枝、叶子全部可参数化
2. **LOD 多级细节**：近中远三级自动切换，远距离自动简化
3. **风动动画**：`tree.update(time)` 实时风吹摇曳
4. **GLB 导出**：浏览器内调整后直接导出 GLB 文件
5. **预设系统**：内置 Ash、Oak 等多种树木预设
6. **树皮材质自定义**：可替换为我们下载的 4K 树皮材质

### 可调参数分类

**树干 Bark**
- 树皮类型（Oak/Pine等）
- 颜色色调 tint
- 纹理缩放
- 平面/平滑着色

**树枝 Branch**
- 递归层级 levels
- 分枝角度
- 每层分枝数量
- 扭曲度 gnarliness
- 长度、半径、锥度
- 外力方向（如垂柳向下生长）

**叶子 Leaves**
- 叶子类型（Oak/Pine等）
- 数量、大小、大小变化
- 颜色 tint（粉色=桃花、红色=枫叶）
- 单面/双面 billboard

## 三、唐代园林树木应用方案

### 垂柳（曲江池边）
- 枝条向下生长：设置 branch.force.direction.y 为负值
- 细长枝条：增加 branch.levels，减小半径
- 嫩绿叶子：leaves.tint 设为嫩绿色
- 风动效果：使用 update(time) 实现柳枝摇曳

### 古松（宫殿庭院）
- 塔形树冠：使用 Pine 类型预设
- 苍劲树干：增加 gnarliness 扭曲度
- 松树皮材质：替换为我们下载的 pine_bark_4k

### 桃花树（曲江春日）
- 粉色叶子/花：leaves.tint 设为粉色
- 树冠饱满：增加叶子数量
- 樱花树皮：替换为 sakura_bark_4k

### 行道树（长安街道）
- 榉树：使用 Japanese Zelkova 形态
- 榉树皮：替换为 japanese_zelkova_bark_4k
- LOD 优化：街道大量树木使用 LOD 模式

## 四、实施步骤

1. **原型验证**：克隆 ez-tree 仓库，在线调整出垂柳/松树/桃花树参数
2. **材质替换**：将我们的 4K 树皮材质替换默认树皮
3. **导出 GLB**：调整好后导出各种树木的 GLB 模型
4. **LOD 生成**：为每种树木生成三级 LOD
5. **场景集成**：导入到长安项目，设置风动动画
