## 一、NatureGenerator 植被系统

### 1. 垂柳 createWillowTree()
- 弯曲主树干（CatmullRom曲线+TubeGeometry）
- 4根主枝桠
- 30根垂悬柳丝（半径仅0.016m，极纤细）
- 动画：随风摇摆

### 2. 古松 createPineTree()
- 倾斜遒劲树干
- 4层云片状松针盘
- 层叠错落布局

### 3. 桃花 createPeachTree()
- 圆柱树干
- 4个十二面体粉红花冠组合
- 动画：树冠微拂

### 4. 竹林 createBambooCluster()
- 7根竹竿随机分布
- 高度4.5-6.5m随机
- 顶端竹叶团

### 5. 荷花 createLotusCluster()
- 6片缺角圆形荷叶
- 1朵粉红荷花

### 6. 太湖石 createTaihuRock()
- 青石基座
- 主峰（十二面体纵向拔高）
- 2块侧峰附石
- "瘦、皱、漏、透"风格

### 7. 芭蕉 createBananaTree()
- 3株假茎聚拢
- 7片大叶片V形折叠下垂
- 江南特色

## 二、CityGateGenerator 城门系统

### 城门结构
| 参数 | 数值 |
|---|---|
| 城墙总宽 | 34m |
| 城台高 | 5.2m |
| 城台进深 | 9.0m |
| 拱券门洞宽 | 4.2m |
| 拱券门洞高 | 4.2m |
| 城楼尺寸 | 14m×7.2m |
| 城楼层数 | 2层 |

### 城门构成
1. 左右青砖城台（Canvas程序化砖纹）
2. 门洞上方连梁过梁
3. 拱券门洞弧形内衬
4. 城墙顶部雉堞（12个垛口）
5. 城台上双层歇山顶城楼

### 砖纹材质
- Canvas 512×512程序化绘制
- 错缝砖缝
- 青灰色城砖基底 #656b69
