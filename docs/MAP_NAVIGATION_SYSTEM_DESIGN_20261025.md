# 地图导航与小地图系统设计

> 设计文档版本：v1.0
> 日期：2026-10-25

---

## 一、小地图

### 位置
- 屏幕右上角
- 尺寸：200×200像素

### 内容
- 玩家位置（箭头）
- 附近地标
- 街道网格
- 坊区名称

### 样式
- 仿古地图风格
- 墨线+淡彩

---

## 二、大地图

### 打开方式
- M键或菜单按钮
- 全屏显示

### 功能
- 浏览全城
- 标记地点
- 路线规划
- 坊区信息

### 样式
- 复古绢本设色
- 参考《长安志图》

---

## 三、导航系统

### 寻路
- A*算法
- 沿街道
- 避开建筑

### 指示
- 屏幕边缘方向箭头
- 距离提示
