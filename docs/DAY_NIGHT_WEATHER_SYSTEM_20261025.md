# 昼夜天气系统详细设计

> 创建时间：2026-10-25

---

## 时间循环

### 现实时间换算
- 游戏内24小时 = 现实20分钟
- 1游戏小时 = 50秒现实时间
- 可暂停、可加速、可手动跳时间

### 关键时间点
| 游戏时间 | 现实时间 | 氛围 |
|---|---|---|
| 5:00 黎明 | 0秒 | 粉紫色天空、晨雾 |
| 7:00 日出 | 100秒 | 金色阳光、长阴影 |
| 12:00 正午 | 350秒 | 白光、短阴影 |
| 17:00 黄昏 | 600秒 | 金橙色、长阴影 |
| 19:00 日落 | 700秒 | 橙红色、灯笼亮起 |
| 21:00 夜晚 | 800秒 | 深蓝黑、星光、月光 |
| 0:00 午夜 | 1050秒 | 最深夜、最安静 |

## 天空系统

### 程序化天空着色器
- Rayleigh散射模拟真实天空颜色
- 太阳位置随时间变化
- 月亮和星星夜晚出现
- 云层：FBM噪声生成

### 关键帧插值
9个关键帧定义天空颜色：
1. 黎明(5:00) — 粉紫
2. 日出(7:00) — 金橙
3. 上午(9:00) — 浅蓝
4. 正午(12:00) — 深蓝
5. 下午(15:00) — 浅蓝
6. 黄昏(17:00) — 金橙
7. 日落(19:00) — 橙红
8. 夜晚(21:00) — 深蓝黑
9. 午夜(0:00) — 近黑

## 天气系统

### 天气类型
| 天气 | 概率 | 视觉效果 | 声音效果 |
|---|---|---|---|
| 晴 | 60% | 正常光照 | 鸟鸣、风声 |
| 多云 | 20% | 柔和光、云层 | 风声 |
| 阴 | 10% | 灰暗、雾 | 风声、远处雷声 |
| 小雨 | 5% | 雨粒子、湿地面反光 | 雨声 |
| 大雨 | 2% | 大雨粒子、水洼 | 大雨声、雷声 |
| 雪 | 2%（冬季） | 雪粒子、地面积雪 | 安静 |
| 雾 | 1% | 远距离雾 | 安静 |

### 季节变化
| 季节 | 月份 | 特点 |
|---|---|---|
| 春 | 1-3月 | 桃花盛开、细雨 |
| 夏 | 4-6月 | 浓绿、荷花、雷雨 |
| 秋 | 7-9月 | 红叶、金黄、秋高气爽 |
| 冬 | 10-12月 | 落叶、雪景、梅花 |

## 灯笼照明系统

### 夜晚灯笼
- 每50m一个沿街灯笼
- emissive材质，橙黄色自发光
- Bloom泛光效果
- 灯节时Bloom强度×2.5

### 室内灯光
- 窗户夜晚透出暖光
- 模拟有人在家
- 概率：平民坊30%，贵族坊80%

### 灯节模式（上元节）
- 全城灯笼点亮
- 万盏孔明灯飘上天
- NPC密度×3
- 烟花特效

---

## 性能优化

- 天空着色器：零纹理，纯GPU计算
- 雨粒子：3000个GPU粒子，不占CPU
- 雾：指数雾，远距裁剪
- 灯光：只在近距离计算实时光，远处用烘焙
