# 新发现开源素材仓库研究（2026-10-25）

> 本轮新发现的4个国风建筑相关开源仓库，可作为素材参考。

## 一、新发现仓库

### 1. voxel-temple
- **仓库**：WEZHCE/voxel-temple
- **描述**：Three.js + Vite 体素化中国古典寺庙群
- **技术**：Three.js, Vite
- **参考价值**：体素风格建筑生成逻辑
- **地址**：https://github.com/WEZHCE/voxel-temple

### 2. chinese-autumn-temple
- **仓库**：aicanbuild/chinese-autumn-temple
- **描述**：Blender + Three.js 中国秋寺互动3D花园
- **技术**：Blender, Three.js, WebGL
- **参考价值**：Blender建模导入Three.js的工作流
- **地址**：https://github.com/aicanbuild/chinese-autumn-temple

### 3. ThreeJS-Stylized-World-Assets
- **仓库**：kk20054/ThreeJS-Stylized-World-Assets
- **描述**：Three.js风格化世界素材库：中国寺庙建筑+草地环境模块
- **技术**：Python, Three.js
- **参考价值**：风格化建筑素材，模块化设计
- **地址**：https://github.com/kk20054/ThreeJS-Stylized-World-Assets

### 4. voxel-chinese-architecture
- **仓库**：Linqiyu-0921/voxel-chinese-architecture
- **描述**：体素风格中式古典建筑群3D场景，飞檐+金色时光照
- **技术**：Three.js, Vite
- **参考价值**：飞檐建筑参数化，光照氛围营造
- **地址**：https://github.com/Linqiyu-0921/voxel-chinese-architecture

## 二、评估

### 优点
- 都是Three.js技术栈，可直接参考代码
- 都是国风建筑主题
- 有Blender工作流参考

### 不足
- 都是体素/风格化，不是写实电影级
- 星标都是0，新项目，质量待验证
- 不是完整的唐式建筑

### 使用建议
- 参考建筑生成逻辑
- 参考Blender工作流
- 参考光照氛围营造
- 不直接使用模型（风格不符）
