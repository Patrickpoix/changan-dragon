# 节日活动系统设计

> 创建时间：2026-10-25

---

## 唐代重要节日

### 1. 上元节（元宵节，正月十五）
**最重要的节日！**
- 全城挂灯笼
- 万盏孔明灯飘上天
- 放假3天（唐代唯一夜间开放的日子）
- 游客爆满

**游戏效果**：
- 全城灯笼点亮，Bloom强度×2.5
- 10000个孔明灯粒子升空
- NPC密度×3
- 烟花特效
- 音乐改为欢庆鼓乐

---

### 2. 上巳节（三月初三）
- 曲江池皇家赐宴
- 文人雅士踏青
- 曲江池游船

**游戏效果**：
- 曲江池游客爆满
- 桃花盛开
- 文人雅集活动

---

### 3. 重阳节（九月初九）
- 登高望远
- 菊花盛开
- 文人赋诗

**游戏效果**：
- 菊花装饰
- 秋高气爽天气
- 文人活动

---

### 4. 中秋节（八月十五）
- 赏月
- 曲江池游船赏月

**游戏效果**：
- 满月大而圆
- 水面月光倒影
- 夜晚活动

---

### 5. 冬至
- 祭祀
- 开始数九

---

## 节日触发
- 游戏内时间到达对应日期自动触发
- 玩家可手动选择"进入节日模式"
- 节日持续整个游戏内一天

## 节日专属内容
- 特殊NPC（节日使者）
- 专属任务
- 收集品（节日灯笼、菊花）
- 特殊对话

---

*节日是开放世界活力的体现，上元节必须做到最壮观。*
