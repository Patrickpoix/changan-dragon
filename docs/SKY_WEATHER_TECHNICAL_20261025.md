## 1. 天空 Shader

### 1.1 Rayleigh 散射
```glsl
// 大气散射近似
vec3 rayleigh = vec3(0.5, 0.7, 1.0) * pow(1.0 - cosTheta, 2.0);
// 太阳方向
float sun = pow(max(dot(normal, sunDir), 0.0), 64.0);
// 最终颜色
vec3 skyColor = rayleigh + sunColor * sun;
```

- 零 HDRI 依赖（程序化生成）
- 日出/日落自动金橙色
- 黎明粉紫色
- 夜晚月亮+星星

### 1.2 层云（FBM）
```glsl
float fbm(vec2 p) {
  float v = 0.0, a = 0.5;
  for (int i = 0; i < 5; i++) {
    v += a * noise(p);
    p *= 2.0; a *= 0.5;
  }
  return v;
}
```

## 2. 昼夜循环

| 参数 | 值 |
|---|---|
| 一天时长 | 20分钟现实时间 |
| 关键帧 | 9个（黎明/日出/上午/正午/下午/日落/黄昏/夜晚/深夜） |
| 插值 | smoothstep 平滑过渡 |
| 夜晚灯光 | 灯笼 emissive + Bloom strength=0.8 |
| 上元灯节 | Bloom=2.0 + 1万孔明灯粒子 |

## 3. 天气粒子

| 天气 | 粒子数 | 说明 |
|---|---|---|
| 雨 | 3,000 | 下落+地面涟漪 |
| 雪 | 2,000 | 飘落+堆积 |
| 梧桐落叶 | 1,000 | 旋转飘落（秋季） |
| 牡丹花瓣 | 500 | 轻柔飘落（春季） |

### 3.1 粒子系统
- GPU 粒子（Points + shader 更新位置）
- 自动回收（出屏幕重置）
- 随风向偏移
- 性能：GPU <10MB，零 CPU 开销
