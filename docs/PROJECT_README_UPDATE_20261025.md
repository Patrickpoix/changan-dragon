# 龙游长安（changan-dragon）

> 等比例复刻唐长安城的开放世界WebGL项目
> 目标：《长安三万里》电影质感 + 《对马岛之魂》开放世界水准

---

## 项目简介

龙游长安是一个浏览器可玩的开放世界项目，等比例复刻唐代长安城（84平方公里），包含108坊、朱雀大街、东西两市、大明宫、曲江池等标志性区域。玩家扮演一只小青龙，自由探索盛唐长安。

---

## 技术栈

- **引擎**：Three.js r169
- **构建**：Vite
- **语言**：JavaScript / TypeScript
- **模型格式**：GLB / glTF
- **压缩**：Draco + Meshopt + KTX2

---

## 素材库

- 51个GLB模型
- 224张PBR贴图
- 8张4K HDRI
- 234个音效 + 4首BGM
- 总量约2.3GB
