# 后处理管线技术方案

> 创建时间：2026-10-25

---

## 目标
达到《长安三万里》电影质感 + 《对马岛之魂》光影氛围

## 后处理链（按顺序）

### 1. RenderPass
- 基础场景渲染
- 输出HDR线性颜色空间

### 2. SSAO (Screen Space Ambient Occlusion)
- 增强建筑角落、屋檐下、门窗洞的环境光遮蔽
- 半径: 0.5m
- 强度: 1.5
- 采样: 16
- 效果: 增强空间感和深度

### 3. Bloom
- 泛光效果，用于灯笼、太阳、高光
- 阈值: 0.85（只让亮于此值的发光）
- 强度: 白天0.3，夜晚0.8，灯节2.0
- 半径: 0.6
- **夜晚灯笼是主要Bloom来源**

### 4. Color Grading (色彩分级)
- 电影LUT查找表
- 暖色调偏移：阴影偏蓝紫，高光偏金黄
- 对比度: 1.1
- 饱和度: 1.05
- 伽马: 1.0

### 5. Vignette (暗角)
- 边缘轻微暗化
- 强度: 0.3
- 半径: 0.8
- 效果：引导视线到中心

### 6. FXAA (快速抗锯齿)
- 移动端默认开启
- 桌面端可换SMAA

## 性能预算

| 效果 | GPU开销 | 桌面 | 笔记本 |
|---|---|---|---|
| SSAO | 中 | ✅ | ⚠️ 可关 |
| Bloom | 中 | ✅ | ✅ 降低强度 |
| Color Grading | 低 | ✅ | ✅ |
| Vignette | 极低 | ✅ | ✅ |
| FXAA | 低 | ✅ | ✅ |

## 性能降级策略

### 高画质（桌面RTX 3060+）
- SSAO全开 + Bloom + 色彩分级 + FXAA
- 阴影: PCFSoftShadowMap 2048
- 分辨率: 100%

### 中画质（桌面GTX 1660）
- SSAO半开 + Bloom + 色彩分级 + FXAA
- 阴影: PCFShadowMap 1024
- 分辨率: 100%

### 低画质（笔记本/核显）
- 关SSAO + Bloom低强度 + 色彩分级 + FXAA
- 阴影: 基础ShadowMap 512
- 分辨率: 75%
