# 地图导航与任务系统设计

> 创建时间：2026-10-25

---

## 地图系统

### 小地图
- 右上角圆形小地图
- 显示玩家位置、方向、附近NPC、建筑
- 可点击放大
- 标注重要地点：城门、寺庙、市场、酒楼

### 大地图
- 全屏地图，唐长安城俯瞰
- 可缩放、平移
- 标注108坊名称、功能
- 显示任务标记
- 显示已发现地点

### 导航指引
- 任务目标在地面有金色光带指引
- 空中有浮动标记
- 距离显示（XX米）

---

## 任务系统类型

### 主线任务
- 跟随小青龙成长
- 了解唐代历史故事
- 参观重要地标

### 支线任务
- 帮百姓找东西
- 帮商人送货
- 帮诗人找灵感
- 帮寺庙做法事

### 随机事件
- 街上偶遇小偷
- 看到有人打架
- 遇到胡人问路
- 市集特价商品

### 收集任务
- 收集唐代文物
- 收集牡丹品种
- 收集诗词碑刻
- 收集美食

## NPC互动

### 对话系统
- 走近NPC按E键对话
- 对话框：NPC头像+名字+对话文字
- 选项分支：闲聊/打听/接任务/交易
- 不同NPC有不同话题

### NPC类型
| 类型 | 互动内容 |
|---|---|
| 百姓 | 闲聊、打听消息 |
| 商人 | 交易商品 |
| 官员 | 接任务 |
| 文人 | 诗词交流 |
| 僧侣 | 听经、祈福 |
| 小贩 | 买小吃 |

---

## 玩家能力

### 飞行能力
- 小青龙形态：自由飞行
- 人形：只能走路
- 飞行高度限制：不能飞过宫城围墙

### 变身系统
- 按R键变龙/变人
- 龙形态：飞行、喷水、呼风唤雨
- 人形态：进建筑、对话、交易

### 特殊能力
- **龙之眼**: 看到隐藏线索
- **喷水**: 浇花、灭火
- **呼风唤雨**: 改变天气

---

## 存档系统
- 自动存档：每5分钟
- 手动存档：随时可存
- 存档位置：localStorage
- 保存：位置、任务进度、收集品、时间
